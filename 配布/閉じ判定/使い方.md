# 閉じ判定 — 使い方

AutoCAD の中で、**モデルの面が閉じているか**をその場で確かめる道具です。
音響シミュレーション用のモデルを作るときに、作りながら何度でも実行できます。

作成：日本環境アメニティ株式会社／幾何音響シミュレーション PJ
版：1.3
動作確認：AutoCAD 2025（AutoCAD LT では動きません）

---

## 1. 何を見る道具か

面をぐるりと囲む辺を全部集めて、**何枚の面に共有されているか**を数えます。
閉じた立体では、どの辺もちょうど 2 枚に共有されます。
1 枚にしか属さない辺が「開いた辺」です。

**ただし開いた辺には、性質のまったく違う 2 種類が混ざっています。**
この道具はそれを必ず分けて出します。

| 区分 | 色 | 何か | どうするか |
|---|---|---|---|
| **自由端** | 🔴 赤 | 他の辺に覆われていない。宙に浮いた片面の板の外周、または**面の抜け** | **閉じた室のつもりなら、ここが作図ミス**です |
| **T字接合** | 🟠 橙 | 同じ直線上の他の辺に覆われている。壁を高さの帯で分けた継ぎ目など | **面としては閉じています。直す必要はありません** |

この 2 つを混ぜて数えると「まだ穴だらけだ」と誤解します。
**見るのは赤い線だけ**で結構です。

> **閉じていないモデルでも構いません。**
> 反射板 1 枚だけを置いた検討など、開いた形のまま計算する使い方もあります。
> その場合は赤い線が出ても問題ありません。「意図した浮きかどうか」を
> 見ていただくための道具です。

---

## 2. 入れ方

1. `閉じ判定.lsp` を分かりやすい場所に置きます。
2. AutoCAD で **`APPLOAD`** コマンドを実行し、`閉じ判定.lsp` を選んで
   「ロード」を押します。
3. コマンドラインに次のように出れば準備完了です。

   ```
   閉じ判定 1.3 を読み込みました。CHECKCLOSED で実行します。
   ```

**毎回読み込むのが面倒なとき**は、`APPLOAD` の画面右下にある
**「スタートアップ スイート」**の「内容」に追加してください。
以後、図面を開くたびに自動で読み込まれます。

### 「ファイルのロードはキャンセルされました」と出たとき

AutoCAD のセキュリティ機能（`SECURELOAD`）が、信頼していない場所からの
読み込みを止めています。次のどちらかで解決します。

- **おすすめ**：`OPTIONS` →「ファイル」→「信頼できる場所」に、
  `閉じ判定.lsp` を置いたフォルダを追加する
- その場しのぎ：`SECURELOAD` の値を `0` にする（AutoCAD を閉じると戻ります）

## 3. 使い方

### `CHECKCLOSED` — 判定する

```
コマンド: CHECKCLOSED
```

結果がコマンドラインに出て、**図面に赤い線と橙の線が描かれます**。

```
=== 閉じ判定 1.3 ===
  面 223 枚 → 辺 1141 本
  ★自由端 14 本／9 かたまり／計 48931.21
      ＝ 宙に浮いた片面の板の外周、または面の抜け。
        閉じた室のつもりなら、ここが作図ミスです。
    T字接合 132 本
      ＝ 同じ直線上の他の辺に覆われている。**面としては閉じています**
        （壁を帯で分けた継ぎ目など。直す必要はありません）

  赤い線＝自由端（レイヤ _閉じ判定_自由端）
  橙の線＝T字接合（レイヤ _閉じ判定_T字接合）
```

線はレイヤ **`_閉じ判定_自由端`** と **`_閉じ判定_T字接合`** に入ります。
橙が邪魔なときは、そのレイヤを非表示にしてください。

### `CHECKNEXT` — 赤いところを 1 つずつ見る

```
コマンド: CHECKNEXT
[閉じ判定] 自由端 1/9　長さ 21227.00　辺 3 本
```

**長いものから順に**画面が拡大されます。繰り返し叩くと次へ進み、
最後まで行くと先頭に戻ります。直したらもう一度 `CHECKCLOSED` を実行して、
赤い線が減るのを確かめてください。

### `CHECKVIEW` — 画面を見やすくする（`CHECKCLOSED` のあと自動で走ります）

判定のあと、次のように画面を整えます。**手で叩き直すこともできます。**

- **面が 1 枚も無い画層を非表示にする**（通芯・文字・ハッチなど）。
  画層名で決め打ちせず、**面を拾えた画層かどうか**で判断します
- **面の画層を透過 70%** にする（中の赤い線が透けて見えます）
- **自由端の線を太く**する（0.5 mm。線の太さ表示を入にします）
- **表示スタイルを X線**にし、面の不透明度を下げる

**視線の向き（カメラ）は触りません。**合わせた向きが崩れないようにしてあります。

### `CHECKVIEWOFF` — 画面の見え方を元に戻す

画層の表示・透過・線の太さを、`CHECKVIEW` を最初に実行する直前の状態に戻します。

> ★**表示スタイルだけは元に戻せません。**AutoCAD が現在の表示スタイルを
> 読み取れる形で持っていないためです。2D ワイヤフレームにするので、
> 必要なら選び直してください。

### `CHECKCLEAR` — 判定の線を消す

```
コマンド: CHECKCLEAR
```

**図面を保存する前に、これを実行して線を消してください。**
（見え方も戻すなら `CHECKVIEWOFF` も実行してください。）

---

## 3b. 直しながら何度でも回せます

**赤いところを直す → もう一度 `CHECKCLOSED`**、の繰り返しが基本の使い方です。

- `CHECKCLOSED` は**最初に前回の線を自動で消します**。`CHECKCLEAR` を
  先に叩く必要はありません
- **判定が描く赤・橙の線は「線」であって「面」ではない**ので、
  次の判定に混ざることはありません
- 画面の整えも毎回走りますが、**元の状態は最初の 1 回だけ控えます**。
  何度回しても `CHECKVIEWOFF` で元どおりになります
  （途中で画層を増やしても、そのとき控えるので戻ります）
- 大きなモデルでは 1 回に**数十秒〜数分**かかります（面の数だけ分解するため）

全部直せると、こう出ます。

```
  ★自由端はありません。面は閉じています。
```

---

## 4. 図面は変わりません

REGION と 3DSOLID は、辺を拾うために**その場で分解し、すぐ UNDO で元に戻して
います**。図面に残るのは、描き足した赤と橙の線だけです。

とはいえ念のため、**実行する前に一度保存しておくこと**をお勧めします。
万一戻せなかった場合は、次のように知らせます。

```
[閉じ判定] ★注意: 元に戻せていないかもしれません（分解前 186 個 → いま 0 個）。
           保存せずに閉じ、開き直してください。
```

## 5. 読める形・読めない形

| 描き方 | 読める |
|---|---|
| **REGION**（面をリージョンで作る） | ○ |
| **3DSOLID**（厚みのある立体） | ○（面のリージョンに分解して見ます） |
| **3DFACE** | ○ |
| **閉じたポリライン**（`POLYLINE` / `LWPOLYLINE`） | ○ |
| ポリフェイスメッシュ | ○ |
| 開いたポリライン・線・円・文字・ハッチング | 読み飛ばします（面ではないので） |

- **モデル空間のものだけ**を見ます。ペーパー空間は見ません
- **ブロックの中は見ません**。判定したい面はブロックから出しておいてください
- 円弧やスプラインで囲まれた面は、**端点だけ**を見ます。本数は合いますが、
  その周りの「自由端か T字接合か」は目安になります（実行時に知らせます）

---

## 6. 判定の細かさについて

「同じ点」とみなす距離は、**拾った面の大きさから自動で決めます**
（対角の 1000 万分の 1。35 m の室なら 3.5 μm）。
図面の単位が mm でも m でも、同じ結果になります。

> 図面全体の範囲（`EXTMIN`/`EXTMAX`）からは決めていません。
> 通芯や文字が遠くに散らばっていると許容が緩くなり、
> **離れた点を同じ点とみなして、開いた辺を見落とす**ためです。

## 7. 検算

同じモデルに対して、当社の Python 版（`geosim/open_edges.py`）と
**同じ結果になることを確かめてあります**。

| モデル | 面 | 辺 | 自由端 | かたまり | 長さ |
|---|---:|---:|---:|---:|---:|
| 閉じた直方体（2×3×1 m） | 12 | 36 | **0** | 0 | — |
| 平面 9 角形＋壁 2 面（開いた形） | 2 | 13 | **11** | 1 | 6349.29 mm |

Python 版も同じく **11 本 / 1 かたまり / 6.35 m** です。

## 8. 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 「面が 1 枚も見つかりません」 | 面がブロックの中にある／ペーパー空間にある／線と文字だけの図面 |
| 「ファイルのロードはキャンセルされました」 | 2 節の「信頼できる場所」を参照 |
| 判定に時間がかかる | 面の数だけ分解するので、数百枚あると数十秒かかります |
| 赤い線が多すぎて読めない | `CHECKNEXT` で長いものから 1 か所ずつ見てください |
| 橙の線が邪魔 | レイヤ `_閉じ判定_T字接合` を非表示にしてください |
| 画面が元に戻らない | `CHECKVIEWOFF`。表示スタイルだけは選び直してください |
| 消えた画層を戻したい | `CHECKVIEWOFF`（面の無い画層を消しているだけです） |

ご不明な点は日本環境アメニティまでお問い合わせください。
