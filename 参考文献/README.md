#### 時間領域の合成について（2026-08-23 の議論）

高速化のために入れた `impulse.impulse_train`（時間領域に置いてから FFT）が
第 3 節の警告に触れないか確認した。**触れない**。

- 論文が警告しているのは**到来時刻をサンプル時刻へ「寄せる」**やり方。
  位相が最大で半サンプルずれるので、**干渉の谷（くし形）の位置が動く**。
- こちらは寄せずに、**窓付き sinc で本来の端数位置に置いている**
  （帯域制限した厳密な遅延）。位相は保たれる。
- 数字：2 パルスの間隔を 3.7135 サンプル（半端な値）にしたときの谷の周波数
  **厳密 5937.8 Hz → 時間領域 5937.8 Hz（一致）／寄せる 5512.5 Hz（7% ずれる）**。
  11.3 kHz までの振幅差 0.00001 dB・位相差 0.00002°。
  タップ数を増やすと**単調に**厳密解へ寄る（式(2) を切り詰めているだけ）。
- ただし**帯域制限つきの一致**なので、波形や伝達関数そのものを波動解と
  突き合わせるときは厳密版（`impulse_method = "exact"`）を使う。
  設定画面で選べる。
