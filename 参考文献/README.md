# 参考文献

最終更新: 2026-08-12（HBN240018）

## PDF 本体はローカルのみ（方針として確定）

論文・書籍スキャンの PDF は **ローカル専用**とし、Git では共有しません。
`.gitignore` の `参考文献/**/*.pdf` で除外済みです。

- 理由: このリポジトリは **public**。著作物を公開リポジトリに置かないため。
- **別端末で clone しても PDF は落ちてきません**（想定どおりの動作です）。
  共有されるのはフォルダ構成とこの README だけ。
- 別端末で PDF が要るときは OneDrive から取得する。
  原本の所在: `OneDrive - ヒビノ株式会社\06_参考文献\`
- **どの文献を参照したかは、この README と `docs/技術説明書.md` に書き残す。**
  PDF が手元になくても議論が追えるようにしておくこと（`fortran/` と同じ考え方）。
