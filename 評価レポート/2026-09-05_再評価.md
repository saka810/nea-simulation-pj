## 5. 追加数値プローブの再現結果

### 5.1 周波数応答の空気吸収

条件: 20 ℃、40 %RH、経路長 100 m、8 kHz、単一経路。

```text
air_absorption=True / False の振幅レベル差 = 0.0000 dB
既存の大気吸収係数から期待される差       = -13.0026 dB
```

`response()` の空気吸収分岐が未実装であることを数値でも再確認した。

### 5.2 coherent の音源スペクトル

条件: PWL `[80, 100] dB`、1 m、2 帯域、単一経路。

```text
coherent = [79.137, 79.131] dB
energy   = [69.137, 89.131] dB
差       = [+10.000, -10.000] dB
```

単一経路では干渉相手がないので、両方式の帯域差は一致すべきである。PWL を平均 90 dB にして全帯域へ使った結果、低帯域は +10 dB、高帯域は -10 dB となっている。

### 5.3 受音球の終端交差

条件: 音線区間 x=0～1.0 m、球中心 x=1.1 m、半径 0.2 m。

区間は x=0.9～1.0 m で球内にあるが、現コードは False を返す。これは「線分と球の交差」ではなく「球中心から無限直線へ下ろした垂足が区間内にあるか」を判定しているためである。

受音球は実寸受音器ではなく候補経路探索用の網なので、仕様として垂足方式を意図する可能性はある。しかし docstring は「球を通過」と説明しており、標準的な線分球交差とは一致しない。少なくとも仕様の明記と壁近傍での収束試験が必要である。

### 5.4 長い室の固有モード

20×5×3 m、250 Hz 以下で、x 方向 20 次の約 171.9 Hz が列挙されなかった。高次であっても cutoff 以下なら含めるべきなので、各軸の最大次数は室寸法と cutoff から求める必要がある。

### 5.5 RT の2点法と回帰法

直線減衰に周期的な揺らぎを重ねた例で、現行の閾値2点法は 1.076 s、評価区間全体の一次回帰は 1.022 s となった。差は約 5.3 %。実際の減衰曲線に反射由来の凹凸やノイズがある場合、初回 crossing だけを使う方法は局所的な変動に左右される。

## 6. 理論面の再評価

### 6.1 残響時間

Schroeder の後方積分と帯域分割という骨格は妥当である。問題は T20/T30 の傾き推定である。`_decay_time()` は -5 dB と -25/-35 dB の初回通過時刻だけを使い、範囲内の全データへ直線を当てていない。

ISO 3382-1:2009 は現在も公開中の版で、ISO は改訂作業中としている。規格法を名乗るなら、指定減衰範囲への最小二乗回帰、適合度、十分な減衰範囲、ノイズ余裕を扱う必要がある。[ISO 3382-1:2009 公式情報](https://www.iso.org/standard/40979.html)

結論: 指数減衰の合成テストに通ることは確認できているが、実測的な凹凸・二重勾配・ノイズ床に対する規格法の実装にはなっていない。

### 6.2 分数オクターブフィルタ

6 次 Butterworth band-pass は実用的な設計選択であり、元 Fortran の巡回畳み込み問題を避ける改善として評価できる。ただし「Butterworth 6 次だから IEC 61260 Class 1 相当」という説明は根拠不足である。IEC 61260-1 は Class 1/2 の周波数応答、許容限界、測定不確かさ等の性能要求を定める。規格マスクへの自動試験を追加するまでは「IEC の中心周波数・帯域端を使う Butterworth フィルタ」と記載するのが安全である。[IEC 61260-1:2014 公式情報](https://webstore.iec.ch/en/publication/5063)

### 6.3 STI

MTF、実効 SNR、MTI、帯域結合という流れは STI の構成を踏まえている。ただし、現コードは男性・女性の両重みを持ち、版番号を示さない。IEC 60268-16:2020 は 2011 版を置き換え、男性音声スペクトルを変更し、女性音声スペクトルと重み係数を削除した。2025年 corrigendum も公式配布版に取り込まれている。[IEC 60268-16:2020 公式情報](https://webstore.iec.ch/en/publication/26771)

6 帯域時に欠損 8 kHz の重みを再正規化する値も、標準の7帯域 STI とは別の近似である。旧版互換値として残すなら、規格版と「非標準帯域の参考値」を結果へ明記すべきである。

### 6.4 幾何音響と反射

音線で候補壁列を探索し、鏡像音源法で反射点を再構築して遮蔽・面内判定する構造は合理的である。鏡映式、三角形交差、距離、エネルギー反射率はテストが厚い。

一方、経路が採用されるためには音線探索段階で一度候補を発見する必要がある。したがって音線数、受音球半径、最大反射回数に対する収束確認が不可欠である。散乱、回折、透過、複素反射位相、音源指向性を扱わないため、適用範囲は主に鏡面反射が支配する中高周波である。

### 6.5 coherent / モード表示

エネルギー反射率から正の平方根を取り、全反射の位相変化を 0 としている。吸音率だけでは複素反射係数の位相は定まらないので、一般材料の干渉ノッチや低周波モードを定量予測するには情報が不足する。剛壁近似または定性的可視化として明記する必要がある。

## 7. 今回新たに強調する実装上の問題

### 7.1 直接音の分類に反射回数を使っていない

`sound_level.band_levels()` は「反射回数 0 のものがあればそれ」とコメントしているが、関数には `reflection_count` が渡されず、実装は常に最早到来パルスを直接音とする。直接経路が遮蔽されている場合、最初の反射音が `direct` に分類される。

総 SPL は変わらないが、直接音/反射音の内訳、説明、後続判断が誤る。`PulseList.reflection_count == 0` を用い、直接音が存在しない場合は direct を `-inf` または欠損として表すべきである。

### 7.2 clarity の原点が最大ピーク

`clarity_measures()` は帯域ごとに `argmax(energy)` を直接音到来とする。強い初期反射が直接音を上回れば C50/C80/D50/Ts の窓が後ろへずれる。また、帯域ごとに別の開始時刻になる。経路から得た幾何学的な直接到来時刻を渡す API にするか、全帯域共通の onset 検出規則を定める必要がある。

### 7.3 CSV のラベルと値の不一致

`sound_level.write_levels()` の `音源パワーレベル_dB` 行は、総合欄に `source_distance` を書く。行名と総合値の意味が一致しない。音源距離は別行にするか、この欄を空にすべきである。

### 7.4 入力有限性の検査

吸音率などの負値検査はあるが、経路によって `NaN` / `Inf` が通る。材料名・周波数を付けて `np.isfinite` を検査し、計算開始前に止める必要がある。
