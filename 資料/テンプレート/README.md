## 提出資料_A4テンプレート（2026-11-06）

標準テンプレートの帯・カード・背景（影・角丸も）をそのまま使い、用紙と書体だけ提出用にしたもの。
作り直しは `py -3.13 資料\テンプレート\powerpoint\make_a4_template.py`（標準テンプレートから生成。手で直した pptx は上書きされる）。
見本は表紙・2列カード＋まとめ・図＋説明・表＋まとめの4ページ。

- 寸法（インチ）：見出し帯の高さ 0.82、左右の余白 0.4、カードの間 0.2、下端の行（資料名・会社名とページ番号）は y 7.88
- 文字の大きさ：表紙タイトル 28pt、ページタイトル 19pt（白・太字）、サブタイトル 11pt、カード見出し 13〜14pt、
  本文 11〜13pt、表 10〜12pt、注記 9.5〜10pt、下端の行 9pt
- 色：帯 `0F766E`、カード見出し `0F4C45`、本文 `2B2F36`、注記 `6B7280`、まとめカード `E3F2F0`、表の罫線 `D0D5DD`
- グラフは PowerPoint のネイティブのグラフで入れ、文字は和文 ＭＳ ゴシック・英数字 Times New Roman にそろえる
  （python-pptx は `a:defRPr` に `a:ea` を足す。作り方は make_a4_template.py の `set_font` を参照）

## 既存の資料に当てる（apply_template.ps1）

別の見た目で作った資料の**写し**に、標準テンプレートの見た目（緑の帯・灰色の地・角丸カード・影・BIZ UDPGothic・
「社内向け 01 / 07」のページ番号）を当てる。最初の使用例は 2026-11-18 の部長会資料（7 枚）。

1. 元の資料を PowerPoint で開き、`SaveCopyAs` などで名前に「標準テンプレート」を含む写しを作って開く
2. `powershell -NoProfile -ExecutionPolicy Bypass -File 資料\テンプレート\powerpoint\apply_template.ps1 -Name "標準テンプレート"`
3. 画像にして全ページを見て、折り返しなどを手で直す

- 区分ラベル（左上の小さい字）と見出しは帯の中に 2 段で入れる（ラベルが長くても入るように）
- 色は紺→緑、薄灰→薄緑、橙の文字→緑に置き換える。グラフの系列の色は変えない（必要なら手で）
- BIZ UDPGothic は Meiryo UI より字幅が広いので、表の文字は 0.92 倍にする。それでも折り返す所は手で直す
- ★グラフの書体は要素ごと（題名・凡例・軸）に名前だけ替える。`ChartArea` にまとめて当てると文字の大きさまで揃ってしまう
- ★PowerShell 5.1 で日本語を含む .ps1 を動かすときは **BOM 付き UTF-8** で保存する（BOM なしだと文字化けする）

## 書体のルール

- **客先へ出す資料**（提出資料・報告書の添付・比較資料）：**和文 ＭＳ ゴシック、英数字 Times New Roman**（2026-11-06 ユーザー指示）。
  PowerPoint・Word では各文字の書式に和文用（`ea`）と英数字用（`latin`）の両方を指定し、テーマの書体も同じにする
- **社内の説明資料**：標準テンプレートの BIZ UDPGothic のまま
- **matplotlib の図**は ＭＳ ゴシックを使わない（本文サイズの日本語が消える。ワークスペースの CLAUDE.md「環境の要点」）。
  提出資料の図は PowerPoint のネイティブのグラフにするか、meas_project の `use_report_font()`（Times New Roman ＋ BIZ UDゴシック）で描く
