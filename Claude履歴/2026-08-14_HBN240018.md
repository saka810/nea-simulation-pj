### 2. PyVista 版モデルビューアの作成（`geosim/view_model_gui.py`）

「Python で GUI 表示できる環境を整えて、先日読み込んだモデルを表示できるように」という依頼。
昨日作った HTML + WebGL 版（`view_model.py`）とは別に、**PyVista のネイティブウィンドウ版**を新設した。

**HTML 版は消していない。** 2 本を並存させる判断:

| | `view_model.py` | `view_model_gui.py` |
|---|---|---|
| 方式 | 自己完結 HTML（WebGL）を書き出してブラウザで開く | PyVista（VTK）のウィンドウ |
| 依存 | なし | pyvista + vtk |
| 強み | **相手に環境構築を求めずに共有できる** | **Python から直接操作できる** |
| 発展先 | Web ベース GUI（G-7） | 音線・音粒子の重ね描き（G-1/G-2）、デスクトップ GUI |

表示内容は同じ（三角形要素・法線矢印・**裏面を赤**・レイヤ色分けと表示切り替え・音源/受音点・
`summary()`）。色は `view_model.LAYER_PALETTE` を import して共有しているので、2 つのビューアで
見え方が揃う。

操作: ドラッグ回転／ホイール拡大縮小／中ドラッグ平行移動／`z`,`x`,`c`,`v` 視点／`n` 法線／
`w`,`s` ワイヤフレーム（VTK 既定）／`r` リセット／`q` 終了。

#### 実装上ハマりどころだった 3 点

1. **巻き順を法線に合わせ直してから PolyData を作る**（`triangles_to_polydata`）
   `read_dxffile` の `orient_normals='flip'` / `'shells'` は**法線だけを反転**して頂点順序を
   触らない。そのまま VTK に渡すと表裏の判定（backface）がモデルの持つ法線と食い違い、
   「裏面を赤で塗る」が嘘になる。頂点順を法線に合わせておけば、あとは VTK の
   `backface_params` に任せるだけで成立する。
   → HTML 版が「法線と視線の内積」で自前判定しているのと**目的は同じ、手段が違う**。

2. **VTK の既定フォントは日本語を持っていない**
   そのままだとレイヤ名（＝吸音材名）や `summary()` が豆腐になる。`japanese_font()` で
   Windows 標準の日本語フォント（`meiryo.ttc` など）を探し、`add_text(font_file=...)` に渡す。

3. **チェックボックスウィジェットは interactor が要る**
   off-screen（`--screenshot`）では追加しないよう分岐した。

#### 描画を実際に確認した（昨日の宿題）

  読み込み側の「法線=inward OK」と一致しており、**裏面判定が効いていることの実証**になった
