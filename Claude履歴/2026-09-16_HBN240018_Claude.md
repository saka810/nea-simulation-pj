### ダブルクリック用の起動ファイルを作った（`シミュレーション起動.bat`）

ユーザー要望「直下にダブルクリックでプログラム開けるファイル置いておいて」。
リポジトリ**直下**に置いた。PowerShell を開かずに始められる。

中身は次のことをしている。

1. `%~dp0` で**自分の場所**を基準に `.venv\Scripts\python.exe` と `geosim\app.py` を探す
2. `geosim` を**作業フォルダにしてから**実行する
   （★ベア名インポートなので、ここを変えると `from mesh import Mesh` が通らない）
3. 引数はそのまま `app.py` に渡す（`%*`）
   → **プロジェクトフォルダを .bat にドラッグ＆ドロップ**すると、その
   プロジェクトを開いた状態で始まる
4. 失敗したときは**理由を日本語で出して `pause` で止める**
   - `geosim\app.py` が無い → 「直下に置いたまま使ってください」＋いまの場所
   - `.venv` が無い → `py -3.10 -m venv .venv` からの手順を表示
     （★端末ごとに作り直すもの。Git では配られない）
   - 途中で落ちた → 「上のメッセージが原因」と書いて画面を残す

決めたこと・踏んだこと。

- ★**ファイルの文字コードは cp932**。`.bat` は cmd.exe がその時の
  コードページで読むので、ダブルクリック（＝システム既定の 932）で
  文字化けしないようにこちらを合わせた。UTF-8 ＋ `chcp 65001` は
  ラベル・`goto` と相性が悪いので採らない
- ★**成功時は `pause` しない**（余計な一手間になる）。黒い画面は
  実行ログとして開いたままにする
- ★**console 版の `python.exe` を使う**（`pythonw.exe` ではない）。
  この PJ は実行ログに警告が出る作り（「吸音率が未指定のレイヤ」など）なので、
  隠すと気づけなくなる
- 動作確認：実際に `.bat` から起動して GUI が出ることと、別の場所へ
  コピーしたときに `:NOAPP` の案内が出て止まることの両方を確認した
- README の「実行」節の先頭に**「ダブルクリックで開く（いちばん簡単）」**を足した
