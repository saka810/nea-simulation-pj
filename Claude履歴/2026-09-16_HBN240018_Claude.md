### 計算そのものの評価（ユーザー質問「尤もらしいと思いますか？」）

コードを読み、検算を 4 つ回して判断した。**結論：虚像法もインパルス応答→残響時間も健全。
ただし構造的な限界が 1 つある。**

1. ★**反射則の自己整合**：実装の `|R(θ)|²` を拡散入射平均すると、入力した残響室法 α に
   **誤差 0.0000 で戻る**（α_s = 0.05〜0.90）。＝音線側と統計理論側は**同じ吸音の物理**
2. ★**虚像法は厳密**：直方体で解析解の鏡像格子と突き合わせ、反射 5 回まで
   **本数（1/6/18/38/66/102）も距離も完全一致**（最大差 0.00e+00 m）
3. ★**探索の網羅は `t_max = r√N/(2c)`**（実測。反射 10 回まで、5 万本・r=0.08 で 41%、
   20 万本・r=0.3 で 100%）。★足りないと**減衰は速く出る**（長くはならない）
4. ★**インパルス応答→T30 は 1 kHz 以上で誤差 1〜3%**。4k/8k のずれは空気吸収＝物理

★★**T30 が理論の 3 倍になる理由を再現できた**。等価吸音面積を揃えて配置だけ変えると
**一様 → 1.09 倍 / 床天井に集中（壁は剛）→ 3.35 倍**。
コードの誤りではなく、**散乱（拡散反射）を一切持たない**ことの帰結。
全モジュールを grep したが**散乱係数も拡散反射も無く、反射は 100% 鏡面**。
市販ソフト（ODEON / CATT / RAVEN）が散乱係数を持つ理由そのもの。

→ **T20・T30 が使えないのは「室の性質」ではなくモデルの限界**（実室はここまで曲がらない）。
  EDT・C50・D50・STI は初期反射が支配的で散乱の影響が小さいので使える、という
  現在の判断は妥当。吸音が一様に近い室なら T30 も信用してよい。

### ★★周波数バンドをベース 2 → ベース 10 へ（ユーザー指示）

「厳密な中心周波数に合わせてほしい／バンドパスも同様では？」→ **そのとおりだった**。
規格の原本（`02_規格・法律/JIS/JIS C 1513-1_2020` ＝ IEC 61260-1:2014）で確認。

- `absorption.exact_midband()` を新設（`f_m = 1000·G^(x/b)`、**G = 10^(3/10)**）
- `absorption.band_edges()` を `f_m·G^(∓1/(2b))`（5.6.1 式(4)(5)）に。
  ★**置き場をここ 1 か所に集約**し、`impulse` のフィルタ・`reverberation` の帯域分割・
  `absorption_curve` の帯域平均を全部通した（幅が食い違うと帯域の値の意味がずれる）
- `impulse.third_octave_bands()` を `15.625·2^(i/3)` からベース 10 へ
- 空気吸収（`sound_level` 3 か所・`reverberation` の 4mV）も厳密値で引く
- ★検証：**規格 表 F.1 の 0.891 25 / 1.122 02 と一致**、ISO 9613-1 表1 とも一致
- ★**呼び値は変えていない**（表・図・ファイル名はそのまま）。
  指標への影響は **0.1〜0.3 ポイント**だけ＝**規格に沿って説明できるようにする変更**

### ★★剛な面（残響室法 α = 0）が NaN になる不具合を修正

`α_s = 0` → `z = ∞` → `4z/(1+z)² = NaN` で、**剛な面を 1 つ指定しただけで
結果が黙って全部 NaN**になっていた（警告も出ない）。
`frequency_response.py` は「まずは剛な面として」使う想定なので実害があった。

- 極限を入れた：`normal_absorption` / `statistical_absorption` は **z = 0 も z = ∞ も 0**、
  `reflection_coefficient` は **z = ∞ で R = +1**
- ★**`random_to_normal` に見張り**（NaN/inf なら理由を告げて止める。黙って流さない）
- 検算：`α_s = 0 → α_n = 0 → |R|² = 1`、拡散入射平均で 0 に戻る。
  **前回 NaN で落ちた実験（壁が完全に剛）が通った**
