#### 残響時間の ISO 化（ユーザー方針）— 差の大きさを実測した

`test.dxf`（2×3×1 m）を音線 20,000 本・反射 25 回で end-to-end に回し、
できたインパルス応答の減衰曲線を 2 点法と最小二乗回帰の両方で読み直した。

- **減衰がまっすぐなら 2 点法でもほぼ合う**（合成した指数減衰で差 1% 未満）。
  ★**これまでの数字が全部でたらめ、ということではない**
- **曲がっているところで大きくずれる**。**125 Hz で +35.7%**、他バンドも 3〜10%
- **いまの曲率は偽警報を出す**。2000 Hz で ISO の C = +0.4%（まっすぐ）なのに
  実装の曲率は −11.8% で「★信用しないこと」が出る
- 回帰にすると **ξ=1000(1−r²)** が無料で付いてくる。63/125 Hz が ξ=178/160 で
  「読んではいけない帯域」を数値で言い切れる

直すもの 3 つ:
(a) `_decay_time` を最小二乗回帰へ（**2 点法は `method="crossing"` で残す**）
(b) 曲率 C を `(T30/T20−1)×100` へ（`decay_measures` は既に両方持っている）
(c) r² / ξ / 使用区間 / 傾きを区分「適合」として表に出す

#### 私が新たに見つけたもの

- **N-1 曲率が ISO の C ではない**（`reverberation.py:413,460`）。docstring は
  「T30 と T20 の食い違い（ISO 3382 の C）」と書いてあり**実装と説明が食い違う**
- **N-2 明瞭度の起点**（`reverberation.py:544`）。`argmax` は帯域フィルタで
  パルスが広がるため低域で真の立ち上がりより**あとに**来る。**低域の C50/D50 が系統的に大きく出る**
- **N-3 ISO 3382-2 の ξ が無い**
- **N-4 1/1→1/3 展開がオクターブ内に約 2 dB の PSD 鋸歯を作る**
  （`expand_to_third_octave` が最寄りオクターブの値をそのままコピーするため。
  帯域幅に比例配分すれば平坦になる）
- **N-5** `write_levels` の「参考／音源パワーレベル_dB」行の**「総合」列に音源距離**が入っている
- **N-6** ISO 3382-1 が求める測定点間のばらつき（標準偏差）と `T_mid` が未出力
- **N-7** `atmosphere` の**気圧の単位が kPa**。Pa で渡すと ρ が 1000 倍になり
  `10log10(ρc/400)` が +30 dB ずれる。警告も例外も出ない（★自分で踏んだ）

#### Codex の評価を補正したところ

- **空気吸収は「ISO 9613-1 型」ではなく「ISO 9613-1 そのもの」**（照合済み）
- **IEC 61260 は「合っている部分」も認めるべき**。直すのは「クラス 1」の 1 行だけ
- **受音球は S1 ではなく S2**。外れるのは**受音点が壁から受音球半径以内**のときだけ
- **S1-6 は「実装が未確定」ではなく「入力データの素性が未確定」**。
  Paris の式の解析解・逆解き・枝の扱い・局所反応の上限 0.951 の検出は質が高い

#### 良いところとして明記したこと

- **音線は経路を見つける網、エネルギーは虚音源から `1/(4πd²)`** という分業のおかげで
  **受音球の断面積による正規化バイアスが原理的に無い**
- 反射率 R(θ) の z の定義が `sound_ray` と `absorption` で二重管理になっていない
- 参照実装を消さない流儀／指紋つき経路キャッシュ／`nref` 不足のエネルギー判定
- 762 テスト全通過（UTF-8 モード。CP932 では `≈` で落ちる）
