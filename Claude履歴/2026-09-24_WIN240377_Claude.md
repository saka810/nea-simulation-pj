### HTML ビューアの操作パネルが見切れる → 不具合 ㉓（修正案はブランチ）

ユーザーが `図/研修室_測定点の確認.html`（09-22 に納品した 3D ビューア）を開いたら、
**右の操作パネルが画面の右端に 45 px ほどしか見えない**（スクリーンショット付き。画面 1920 幅）。

#### 原因（ブラウザで再現して確かめた）

- `view_model.py` の CSS は `#wrap{display:flex}` の中に `canvas{flex:1}` と
  `#panel{width:300px;flex:none}`。**キャンバスに `min-width` の指定が無い**
- 描くたびに `canvas.width = clientWidth × devicePixelRatio`（383 行）と実寸を書き換える。
  フレックスの子の既定 `min-width:auto` は**中身の大きさ＝キャンバスの実寸**なので、
  ★**広げられても縮められない**。縮んだ分だけパネルが画面外へ押し出される
- 再現：1920 幅で開いて 1280 幅へ縮めると、パネルが **26 px** しか見えず、描き直しても戻らない
- ★最初は「表示倍率 > 1 のとき描くたびに膨らむ」と見立てたが、**開いたままの状態では
  膨らまなかった**（Chromium は実寸だけでは広げない）。**縮めたときに戻らない**のが本体だった。
  見立てどおりにならなかったので条件を変えて探し直した

#### 手当て

- **直し方は 1 行**：`canvas{flex:1;min-width:0;min-height:0;…}`。
  2560 → 1920 → 1280 のどの幅でもパネル 300 px がすべて見えることを確認
- **納品済みの HTML 3 つ**（研修室・研修室の旧_測点v1・視聴覚室）を直接書き換えて
  OneDrive に反映（ハッシュ一致・修正済みを確認）
- **プログラムの修正案はブランチ `fix/WIN240377_html_panel`**（`view_model.py` 1 行＋
  `PROGRAM_STRUCTURE.md` の注記）。**1100 / 1100 件 OK**。merge はしていない
- 不具合報告に **㉓** として追記。★merge されるまでは、新しく書き出した HTML に
  また同じ症状が出る

#### 確かめ方のメモ

- 内蔵ブラウザはローカルファイル（file://）だと画面操作ができないので、
  `python -m http.server` で `図/` を配って開いた
- 内蔵ブラウザの枠が隠れていると `requestAnimationFrame` が止まるので、
  `resize` イベントを投げて待つと固まる。**`draw()` を直接呼んで**寸法を測った
- ウィンドウ幅は `resize_window` で 2560 / 1920 / 1280 を順に当てて確かめた
