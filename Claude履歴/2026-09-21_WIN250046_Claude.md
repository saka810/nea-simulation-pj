#### 中身の骨子

- **なぜ要るのか**：階段教室の実測（T30 が理論の 3.35 倍／ξ 10〜25／曲率 10% 超）。
  ★等価吸音面積をそろえて配置だけ変える実験で再現できているので、
  **室の性質ではなくモデルの限界**だと言い切れる
- ★★**いまの作りと、散乱がそのままでは入らない理由**（この資料の核心）。
  3 段目の**虚音源バックトレースが鏡像で検算する**ので、
  **散乱した音線は 1 本残らず却下される**。反射の式を 1 行変える話ではなく、
  計算の骨組みを変える話になる
- **用語の整理**：ご指示の「拡散係数」は、シミュレーションで使う量としては
  **散乱係数 s（ISO 17497-1）**。**拡散係数 d（ISO 17497-2 / AES-4id）は別物**で
  拡散体の性能比較に使うもの。資料は以後 s で統一した
- **方式 A〜E**：ベクトル法（VBS）／確率的散乱（モンテカルロ）／2 次音源（diffuse rain）／
  放射伝達（radiosity・ART）／幾何でつくる
- **比較表**：計算コスト・精度・s の設定難易度・モデル化の手間・**既存コードへの影響**・
  **位相（複素和）の維持**・市販ソフトでの採用
- ★★**このプログラム固有の論点：位相**。インパルス応答は位相を持つ複素和（査読論文 式(2)）
  なのに、散乱音には決まった位相が無い。**「散乱したかどうか」で切り分ける**提案
  （鏡面は複素和のまま・散乱はエネルギー）にした。何次反射までで切るより素直
- **ロードマップ**：段 0 物差しを控える → 段 1 B+C → 段 2 条件表に散乱率の列 → 段 3 校正
- **s の決め方**：凹凸の深さと波長／面の大きさ（縁の効果）／★**二重に数えない**。
  材料別・周波数別の目安表を付けた。★**s = 0 にしない**（0.05〜0.1 を下限）
- **階段教室への当てはめ**：形が作り込まれているので s は小さめ（反射板・段床 0.05〜0.10）。
  ★**未作図の客席は 0.6〜0.7**。いちばん効くのは反射板の隙間（結合空間の「のど」）
- **検証の基準**：曲率・ξ・T20/T30 の差が縮むこと。
  ★**EDT・C50・STI と逆二乗則は動かないこと**（動いたら入れ方を間違えている）
