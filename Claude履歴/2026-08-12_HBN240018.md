#### 「元の数式はしっかりした数式か？」→ **はい、正しい式です**

`energy_decay`（元コード1093行）の反射率は **局所反応性（locally reacting）壁面の斜入射圧力反射率**。導出は

1. 法線入射吸音率 α₀ から法線入射の圧力反射率 |R₀| = √(1 − α₀)
2. 規格化音響インピーダンス（実数と仮定） z = (1 + |R₀|) / (1 − |R₀|)
3. 斜入射の圧力反射率 R(θ) = (z·cosθ − 1) / (z·cosθ + 1)
4. 分母分子に (1 − |R₀|) を掛けて整理 →
   R(θ) = ((1+√(1−α₀))·cosθ − (1−√(1−α₀))) / ((1+√(1−α₀))·cosθ + (1−√(1−α₀)))

これは元コードの式そのもの。エネルギー反射率は |R(θ)|²。挙動も妥当（θ→90° で |R|→1＝掠め入射は吸音されない、
θ=0 で残存エネルギー = 1 − α₀）。

**旧実装がなぜ致命的だったか**：第2項も `(1 + √(1−α))` だと分母分子から共通因子 (1+√(1−α)) が約分され、
`R = (cosθ − 1) / (cosθ + 1)` になる。つまり **吸音率がまったく効かず**、しかも垂直入射（cosθ=1）で R=0、
すなわち**どんな材料でも完全吸音**という挙動になっていた。

**注意点**：`abs(...)**2 * enertmp(l)` を「2乗の後に自身を掛けている＝3乗では？」としたコード内の疑問は誤読。
2乗するのは圧力反射率 R、最後に掛ける `enertmp` は累積エネルギーで別物。
また想定は**垂直入射吸音率**。NEA でよく使う残響室法吸音率は 1 を超えることがあり `sqrt(1 - α)` が NaN になるため、
Paris の式を逆解きして α₀ または z を求める前処理が別途必要（未実装、要検討）。
