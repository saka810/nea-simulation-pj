# DXF データの作り方

最終更新: 2026-08-12（HBN240018）

`geosim/read_dxffile.py` が読める DXF を CAD 側でどう作るか、という運用ルール。
リポジトリ直下の `test.dxf` が最小の実例（2×3×1 m の直方体）。

## 結論（この 5 つを守れば読める）

| # | ルール | 理由 |
|---|---|---|
| 1 | **面はポリフェイスメッシュ（POLYLINE）か 3DFACE で作る** | この 2 つだけ読む。ソリッドや LWPOLYLINE は読み飛ばす |
| 2 | **レイヤ名 = 吸音材の識別子にする** | 吸音率 CSV の 1 列目と突き合わせる。日本語可 |
| 3 | **室は閉じた形状にする** | 法線の向きを符号付き体積から自動判定できる |
| 4 | **単位は mm でよい（$INSUNITS が入っていれば自動換算）** | ヘッダの `$INSUNITS` を見て m に直す |
| 5 | **音源は `src` レイヤ、受音点は `rec` レイヤに POINT を置く** | 座標をコードに書かなくて済む |

---

## 1. 面のつくり方

読めるのは次の 2 つ。

- **POLYLINE のポリフェイスメッシュ**（`70` に 64 が立っているもの）
  `test.dxf` はこれ。頂点 VERTEX（`70=192`）が並び、そのあとに面レコード VERTEX（`70=128`）が続く。
  面レコードの `71`〜`74` が頂点番号（1 始まり）で、4 番目が 0 なら三角形。
- **3DFACE**
  単体で 3〜4 頂点の面を表すエンティティ。4 点目が 3 点目と同じなら三角形として扱う。

**三角形でも四角形でもよい。**四角形以上は読み込み時に扇状（fan）に三角形分割される。
ただし**四角形は 4 点が同一平面上にあること**。ねじれていると分割の仕方で形が変わってしまう。
迷うなら三角形で作るのが確実。

### 1 つのレイヤに複数の POLYLINE を置いてよい

`test.dxf` では壁 4 面がすべてレイヤ `2` にまとまっている。
**吸音材を変えたい面だけレイヤを分ける**運用がいちばん楽。

```
レイヤ '1' … 床      （POLYLINE 1 枚 → 三角形 2 枚）
レイヤ '2' … 壁 4 面 （POLYLINE 4 枚 → 三角形 8 枚）
レイヤ '3' … 天井    （POLYLINE 1 枚 → 三角形 2 枚）
```

### 避けること

- **面積ゼロの面（縮退面）**。3 点が一直線に並んだ三角形。
  法線が計算できないので自動で捨てるが、意図せぬ穴になるので CAD 側で作らない。
- **面の重複**。同じ場所に 2 枚あると音線が余分に反射する。
  読み込み後に出る表面積を検算するとよい（後述）。

## 2. レイヤ名 = 吸音材の識別子

読み込み時に**レイヤ名をそのまま材料名として扱い**、吸音率 CSV の 1 列目と突き合わせる。

```csv
layer,a1,a2,a3,a4,a5,a6
1,0.02,0.03,0.04,0.05,0.05,0.06
2,0.10,0.12,0.15,0.18,0.20,0.22
コンクリート,0.02,0.02,0.03,0.03,0.04,0.05
グラスウール25mm,0.15,0.35,0.65,0.85,0.90,0.85
```

- **数値 ID（`1`, `2`, `3`）でも材料名（`コンクリート`）でもよい**。
  後から見て分かるのは材料名なので、**材料名を推奨**。
- 日本語のレイヤ名も読める（DXF のエンコーディングは UTF-8 → CP932 → latin-1 の順に試す）。
- CSV に無いレイヤがあると**警告が出て既定値 0.1 が使われる**。警告は無視しないこと。

サンプル: `data/absorption_sample.csv`

> **⚠ 入れるのは垂直入射（法線入射）吸音率**。残響室法（乱入射）吸音率は 1 を超えることがあり、
> `sqrt(1 - α)` が NaN になって計算が壊れる。詳細は `TODO.md` の D-7、
> `docs/技術説明書.md` 7.3 節。

## 3. 室は閉じた形状にする

音線追跡は**法線が室内向き**であることを前提にしている（判定を `v·n < 0` の符号ひとつで書くため）。

CAD の頂点並び順で法線の向きが決まるので、そのままでは外向きになっている場合がある。
そこで読み込み時に**符号付き体積 V = (1/6)Σ x₁·(x₂×x₃)** を計算し、

- `V < 0` … すでに内向き → そのまま
- `V > 0` … 外向き → 全部反転

としている。**閉じていて巻き順が一貫していれば、凸でなくても正しく判定できる**のが利点。

`test.dxf` では `V = -6.0000 m³`（室容積 2×3×1 = 6 m³ の負値）と出て、
CAD 時点ですでに内向きだったことが確認できる。

### 閉じていない形状を扱いたいとき

`orient_normals` を切り替える。

| 値 | 挙動 | 使う場面 |
|---|---|---|
| `'auto'`（既定） | 符号付き体積で全体を判定 | 閉じた形状。通常はこれ |
| `'cad'` | CAD の巻き順をそのまま信じる | 自分で向きを揃えてある場合 |
| `'inward'` | 面ごとに重心方向へ強制 | **凸形状限定**の応急処置 |
| `'outward'` | 面ごとに重心の逆へ強制 | デバッグ用 |

体積がほぼ 0 になると「閉じていないか巻き順が不揃い」と警告が出る。

## 4. 単位

DXF ヘッダの `$INSUNITS` を見て m に換算する。`test.dxf` は `$INSUNITS = 4`（ミリメートル）。

| $INSUNITS | 単位 | m/単位 |
|---|---|---|
| 0 | unitless（判定不能） | — |
| 1 | インチ | 0.0254 |
| 2 | フィート | 0.3048 |
| 4 | **ミリメートル** | **0.001** |
| 5 | センチメートル | 0.01 |
| 6 | メートル | 1.0 |

（他にキロメートル・ヤード・ミクロンなども対応。`INSUNITS_TO_METER` を参照）

- **`$INSUNITS = 0`（unitless）だと判定できない**ので警告が出て m 扱いになる。
  CAD 側で単位を設定するか、`read_model(..., unit='mm')` と明示指定する。
- 文字列（`'mm'`, `'cm'`, `'m'`, `'km'`, `'inch'`, `'ft'`）でも数値（m/単位）でも指定できる。
- **明示指定はヘッダより優先される**。CAD の設定が信用できないときはこれを使う。

## 5. 音源・受音点も CAD に入れておける

**`src` レイヤに POINT を置けば音源、`rec` レイヤなら受音点**として読む。
`test.dxf` は音源 (1000, 500, 500) mm、受音点 (700, 2000, 500) mm が入っている。

```python
model = rd.read_model("test.dxf")
model.source_points    # [array([1.0, 0.5, 0.5])]
model.receiver_points  # [array([0.7, 2.0, 0.5])]
```

`procedure.process()` に `soundsource_point=None, reciever_point=None` を渡すと
DXF 側の値が使われるので、**座標をコードに書かなくて済む**。

- レイヤ名は大文字小文字を区別しない。`source` / `receiver` / `音源` / `受音点` も可
  （`source_layers` / `receiver_layers` 引数で変更できる）
- **複数点を置いてもよい**。リストで全部返る。受音点を何箇所も評価したい場合に使える
  （現状のパイプラインは先頭の 1 点だけを使う。複数受音点への対応は今後の課題）

## 6. 読み込めたかの確認方法

`read_model()` は読み取り結果を print する。ここを見れば大半の作図ミスは分かる。

```
[read_dxffile] 三角形メッシュ: 12 枚
[read_dxffile] 単位: 1 CAD単位 = 0.001 m（$INSUNITS=4）
[read_dxffile] レイヤ別の枚数: {'1': 2, '2': 8, '3': 2}
[read_dxffile] 音源: [[1.0, 0.5, 0.5]]
[read_dxffile] 受音点: [[0.7, 2.0, 0.5]]
[read_dxffile] 寸法: [2.0, 3.0, 1.0] m (min=[0.0, 0.0, 0.0])
[read_dxffile] 法線の向き: 符号付き体積 -6.0000 m³ < 0 → すでに内向き
```

チェックポイント:

- **寸法**が意図した室の大きさになっているか（単位換算のミスがここで出る）
- **符号付き体積**の絶対値が室容積と一致するか（閉じていないと合わない）
- **レイヤ別の枚数**が想定どおりか（レイヤの割り当て漏れがここで出る）
- **三角形の枚数**（四角形 1 枚 = 三角形 2 枚）
- **読み飛ばし**の行が出ていないか（縮退面・面レコード不正）
- **吸音率が未指定のレイヤ**の警告が出ていないか

さらに**表面積を検算**すると分割の健全性まで確認できる。

```python
area = sum(0.5 * np.linalg.norm(np.cross(m.vertexes[1] - m.vertexes[0],
                                         m.vertexes[2] - m.vertexes[0]))
           for m in model.mesh)
# test.dxf → 22.0000 m²（= 2×(2×3 + 3×1 + 1×2)）ぴったり一致すれば重複・欠落なし
```
