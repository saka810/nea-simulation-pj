# 使い方マニュアル

幾何音響シミュレーション（音線法 ＋ 虚音源バックトレース）の**操作手順書**。
「何を用意して、どのボタンを押すと、どのファイルが出てくるか」を順に書いてある。

- 数式とプログラムの中身 … `docs/技術説明書.md`
- CAD 側の作図ルール（詳細版）… `docs/DXFデータの作り方.md`
- 各モジュールの役割・既知の問題 … `PROGRAM_STRUCTURE.md`

---

## 0. 全体の流れ

```
  ① DXF を用意する          室形状・音源（src）・受音点（rec）を CAD で描く
        ↓
  ② 条件入力                 python app.py
        ↓                     プロジェクトフォルダ・DXF・音線数・大気条件など
  ③ 条件表.xlsx を作る        どのレイヤに、どの吸音材を貼るか
        ↓
  ④ 面を確認                 法線の向き（緑=OK / 赤=要反転）と吸音材の色を目で見る
        ↓
  ⑤ 計算する ▶               数分〜数十分。結果 CSV ＋ 図 PNG ＋ Excel が出る
        ↓
  ⑥ 結果を見る               Excel（人が読む）／CSV（機械が読む）／3D 画面
```

②〜⑥ は**同じウィンドウの往復**で、`app.py` が順に開く。
④で保存すると②に戻り、そこから⑤へ進む。

## 2. DXF を用意する

CAD 側で守ることは 4 つだけ。詳細は `docs/DXFデータの作り方.md`。

| 項目 | 決まり |
|---|---|
| 面 | 3DFACE / ポリフェイスメッシュ / 閉じた 3D ポリライン。**REGION・3DSOLID はそのままでは読めない**（下記） |
| レイヤ | **レイヤ ＝ 吸音材の単位**。壁・床・天井・吸音板…を別レイヤに分ける |
| 音源 | レイヤ名 `src` に点を置く |
| 受音点 | レイヤ名 `rec` に点を置く。**`rec1` `rec2` `rec3` のような連番レイヤでもよい**（測線ごとの評価に使う） |
| 単位 | DXF の `INSUNITS` を見る。mm でも m でもよい |

補足：

- **音源と重なる受音点は自動で外す**（そこでは音圧が発散するため）。
- 法線の向きは CAD で気にしなくてよい。読み込み時に「自動」で揃える（次章）。
- **REGION / 3DSOLID の DXF** は面に変換してから読む。AutoCAD が入っている端末なら：

```powershell
python dxf_faces.py "C:\...\室.dxf"        →  室_faces.dxf ができる
```

  元のファイルは触らない。円弧・スプライン・穴あき（輪が 2 つ以上）は数えて知らせる。
  ただし**直方体の 3DSOLID だけは、そのままでも 8 隅から面を起こせる**（半無響室など）。

計算条件を決める前に、**容積と面積が想定どおりか**を見ておくと後が楽。

```powershell
python read_dxffile.py ..\test.dxf
```

```

[read_dxffile] 単位: 1 CAD単位 = 0.001 m（INSUNITS=4）
[read_dxffile] 音源: [[1.0, 0.5, 0.5]]
[read_dxffile] 受音点: [[0.7, 2.0, 0.5]]
[read_dxffile] 総表面積: 22.000 m2
[read_dxffile] 容積: 6.000 m3（法線（発散定理））  平均自由行程 1.091 m
[check] 作図チェック: 問題は見つかりませんでした
```

**自由端**（赤・本当に穴が空いている）と **T字接合**（橙・壁を帯で分割しただけ。問題なし）を

## 3. 条件入力（`app.py` の最初の画面）

`python app.py` を実行すると出る。上から順に埋める。

### 3-1. ファイル

| 欄 | 意味 |
|---|---|
| プロジェクトフォルダ | **結果と図の保存先**。既存フォルダを選ぶと前回の条件を読み込む |
| 対象室名（任意） | 結果ファイル名の頭に付く。**空欄なら DXF のファイル名**を使う |
| モデル（DXF） | 室形状。音源・受音点も `src` / `rec` レイヤから読む |
| 条件表（xlsx） | レイヤー名 → 材料番号の対応表。**シート 1 枚が条件 1 つ** |
| 条件（シート） | 使う条件を選ぶ。**シート名が条件名**になり、結果ファイル名に入る |

条件表がまだ無ければ、その場の**「条件表を作成」**ボタンで作れる（次章）。

### 3-2. 計算条件（幾何音響）

| 欄 | 既定 | 決め方 |
|---|---|---|
| 音線数 | 200000 | 多いほど後期の経路を拾える。20 万本が目安 |
| 最大反射回数 | 120 | **35 dB 減衰するまで**必要。足りないと残響が短く出る |
| 受音球の半径 [m] | 1.0 | ★下記。小さすぎると残響が短く出る |
| インパルス応答の長さ [s] | 3.0 | 残響時間より十分長く。「残響から推定」ボタンで理論値の 1.5 倍が入る |

**★受音球の半径がいちばん間違えやすい。**

受音球はエネルギーを集める器ではなく、**経路を見つけるための網**。
エネルギー自体はバックトレースが厳密に出し、成り立たない経路は却下する。
ある経路が見つかる確率はおよそ `N·r²/(4d²)`（N=音線数、r=半径、d=経路長）で、
`d = ct` だから**遅い時刻ほど取りこぼす**。その結果、後期のエネルギーが足りず
**残響時間が短く出る**。

目安は次の式。

```
t_max = r√N / (2c)  >  求めたい減衰時間
```

372 m³ の室・音線 20 万本では、既定の 0.15 m だと 0.098 秒ぶんしか拾えず、
T30 が 3〜4 割短く出た（2026-08-14 の実データ）。この例では r ≥ 1.0 m で収束した。

> **半径を変えても値が動かないことを確かめてから、数字を使うこと。**

「音線の飛び方を見る」ボタンで、音線が球状に均等に出ている様子だけ先に確認できる
（室形状とは関係ないので、モデルが無くても見られる）。

### 3-3. 室・音源・大気

| 欄 | 意味 |
|---|---|
| 室容積 [m³] | 統計残響式（Sabine ほか）に使う。**空欄なら閉じた形状から自動算出**。「モデルから見積」ボタンで容積・表面積・平均吸音率が出る |
| 音源 PWL [dB] | **空欄なら音圧レベルは相対値**（Lw = 0 dB として計算し、出力にもそう書く） |
| 背景騒音 [dB] | STI の SNR に使う。**PWL と両方そろっていないと効かない** |
| 温度 [℃] / 相対湿度 [%] / 気圧 [kPa] | **音速と空気吸収の両方が連動する**。既定 20℃ / 40% / 101.325 kPa |

> ★**気圧の単位は kPa**（101.325）。Pa を入れると密度が 1000 倍になり、音圧レベルが
> 30 dB ずれる。桁を見て止めるようにはなっているが、入力時に気をつけること。

### 3-4. 設定（プルダウン）

| 欄 | 選べるもの | 備考 |
|---|---|---|
| 周波数バンド | 8 バンド（63〜8k Hz）/ 6 バンド（125〜4k Hz） | 6 バンドだと STI の 8 kHz が無いので重みを外して正規化し、警告が出る |
| 法線の向き | **自動**（閉じていれば内向き、開いていれば CAD のまま）/ CAD のまま / 面ごとに室内側 / シェル単位 / 全反転 | ふつうは「自動」 |
| 閉じたモデル | **自動** / 閉じている / 閉じていない | ★下記 |
| インパルス応答の合成 | **高速**（時間領域→FFT）/ 厳密（式(2) をそのまま） | 指標を出すだけなら高速で足りる。**FDTD などの波動解と波形を突き合わせるときだけ厳密** |
| 統計残響式も計算する | チェック | Sabine / Eyring / Eyring-Knudsen |

**★「閉じたモデル」は利用者が決めること。**
一面反射板だけの検討もあるので、自由端があること自体はモデルの側では良し悪しが決まらない。

- **閉じている** … 自由端があれば**作図ミス**として警告する
- **閉じていない** … 自由端を指摘しない（注意止まり）
- **自動**（既定）… どちらの可能性も伝える。決めつけない

ただし容積が目安になることは、どの設定でも必ず伝える（発散定理は閉曲面でしか
成り立たないため）。

### 3-5. 画面下のボタン

| ボタン | 動き |
|---|---|
| 条件だけ保存 | `project.json` に書いて閉じない |
| 面を確認…（法線・吸音材） | 3D 画面を開く（第 5 章） |
| 前回の結果を見る | **計算し直さずに**、保存済みの結果を読んで図を描き直し、可視化画面を開く |
| 全条件を一括 ▶▶ | 条件表の全シートを順に回す（第 4-3 節） |
| 計算する ▶ | 計算を始める（第 6 章） |

## 4. 条件表（`条件表.xlsx`）＝ 吸音材の割り当て

**CAD を触らずに材料を差し替えるための入力ファイル。**プロジェクトフォルダ直下に置く。
入力なので、ファイル名に対象室名・条件名は付けない。

条件入力の**「条件表を作成」**を押すと、DXF のレイヤを並べた雛形ができる
（計算時に無ければ自動でも作られる）。

### 4-1. シート「吸音率」＝ 材料の一覧

| 番号 | 材料名 | 63 | 125 | 250 | 500 | 1000 | 2000 | 4000 | 8000 | 種類 | 備考 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | コンクリート | 0.02 | 0.02 | 0.03 | 0.04 | 0.05 | 0.05 | 0.06 | 0.06 | 垂直入射 | |
| 2 | 石膏ボード | 0.10 | 0.10 | 0.12 | 0.15 | 0.18 | 0.20 | 0.22 | 0.22 | 垂直入射 | |

- **1000 材料ぶんの枠**がある。PJ 固有の吸音データはここに置けばよい
  （これがあれば `absorption.csv` は要らない）。
- **番号の列は `=ROW()-1`**（行の位置がそのまま材料番号）。触らない。
- ★**「種類」は必ず選ぶ**（ドロップダウン）。
  - **垂直入射**（法線入射）… 音響管（インピーダンス管）で測ったもの
  - **残響室法**（乱入射）… 残響室で測ったもの。1 を超えることがある
  残響室法の値は Paris の式で自動的に垂直入射へ変換される。
  **取り違えると吸音を大きく誤る**（残響室法 0.50 は垂直入射では 0.34 相当）。

### 4-2. その他のシート ＝ 条件 1 つ

シート 1 枚が条件 1 つで、**シート名が条件名**になる（既定では「現状」）。

| 番号 | 区分 | レイヤー名 | 材料番号 | 安全率 | 材料名（参考） | 面数 | 面積_m2 |
|---|---|---|---|---|---|---|---|
| 1 | レイヤ | 壁 | 2 | 0.8 | 石膏ボード | 8 | 10.0 |
| 2 | レイヤ | 床 | 1 | | コンクリート | 2 | 6.0 |

- ★**書き換えるのは「材料番号」と「安全率」の列だけ。**
  材料名は VLOOKUP の参考表示で、読むときは見ない（名前を打つと全角・半角の
  ミスタイプが起きるため）。
- **安全率**は「吸音率を見過ぎないように間引く」係数（例 0.8）。**未入力なら掛けない**。
  カタログ値に掛けてから垂直入射へ変換する。
- 面数・面積は毎回書き直される参考列。
- **条件シートに吸音率は載せない**（ミスリードを避けるため。吸音率は「吸音率」シートだけ）。
- 利用者が書いた材料番号は**絶対に上書きされない**。モデルから消えたレイヤも
  `（モデルに無し）` として残る（前の設定を見返せるように）。
- 作った体裁（列幅・書式・足した列）は計算しても壊れない（その場で直すだけ）。

区分の欄には、`face_editor` で面に直接貼った材料が `面ごとの指定` として記録される
（入力ではなく記録）。

### 4-3. 条件を増やす・一括で回す

シートを複製して名前を変えるだけ（シート名が条件名）。

```powershell
python run_project.py "C:\...\プロジェクト" --conditions
```

または条件入力の**「全条件を一括 ▶▶」**。

- **結果ファイル名は「対象室名 ＋ 条件名」**になるので混ざらない。
- **2 件目以降は速い。**経路（反射面の並びと入射角）は吸音に依らないので、
  1 件目で保存した `結果/recN/<室>_経路.npz` を使い回してエネルギーだけ計算し直す。
- 最後に**条件を横に並べた比較表**（`<室>_まとめ_条件比較.csv`）と、
  Excel の「条件比較」シートができる。

> ★注意：材料の**分け方**（どのレイヤをどの材料にするか）を変えるとパッチの切れ目が
> 動くので経路も変わる。そのときは自動でやり直す。吸音率の**値**だけ変えたときは
> 使い回す。`--no-reuse` で使い回しを切れる。

## 5. 面を確認する（法線・吸音材）

条件入力の**「面を確認…（法線・吸音材）」**、または：

```powershell
python face_editor.py "C:\...\プロジェクト"
```

**ここで見るのは 2 つ。**

1. **法線の向き** … 緑 = 内向き（OK）／赤 = 外向き（要反転）／灰 = 判定できない
2. **吸音材** … `m` で切り替えると、材料ごとの色で塗られる

**操作は「選ぶ → 適用する」の二段階。**枠で囲んだ瞬間には何も起きない。
選んだ面は橙で塗られ、外周が線で描かれる。

| キー | 動き |
|---|---|
| `r` | 枠で選ぶ（もう一度押すと解除） |
| `0` / `j` / `h` | 選択を解除 / 全部を選ぶ / 選択を反転 |
| `k` / `t` | 同じ平面の面を選ぶ / 同じ平面かつ同じレイヤ |
| `l` / 数字 | 同じ吸音材の面を選ぶ / そのレイヤを選ぶ（1〜9） |
| `y` | 面グループ ⇔ 三角形（選択の単位を切り替え） |
| `m` | 法線 ⇔ 吸音材（表示モード） |
| `i` | 選んだ面の法線を反転（選択が空なら全部） |
| `a` / `d` | 自動判定にする / CAD の巻き順に戻す |
| `n` / `o` | 法線の矢印 / 不透明度の対象を切り替え |
| `z` `x` `c` `v` | 視点（上・正面・横・等角） |
| `w` | 向きを調整する受音点を切り替え（受音点が複数のとき） |
| `g` | いまの画面を画像で保存 |
| `PageUp` / `PageDown` | 左の欄を送る |
| `s` / `q` | **保存して閉じる** / 保存せずに閉じる |

- **面は「同一平面パッチ」を 1 枚として見せる**（三角形の辺は描かない）。
  1 枚の壁が三角形に割られていても、まとめて 1 枚として選ばれる。
- 左パネルの材料をクリックすると、選んだ面に吸音材を貼れる。
  レイヤで分けられないモデル（1 つの 3DSOLID など）はここで貼る。
  保存先は `materials.json`。
- 法線の反転指定は `normals.json` に保存される。
  **DXF が変わって面数が食い違うと、黙って使わずに知らせる。**
- **受音点の向き**（「人」の正面方向）も一括で決められる。
  「音源側を向く」と「+X / +Y / −X / −Y」のボタン。伝搬方向の図で使う。
- 左パネルの**「画角を保存」「画角を読込」**で、見る向きを `視点.json` に出し入れできる。
  名前を付けて何本でも持てる。**面の確認と結果画面で同じファイル**なので、
  モデルを見た向きのまま結果を見られる。

数値の欄は Excel と同じ**スピンボックス**。枠を押すとその場で打ち込める
（`Enter` 確定 / `Esc` 取り消し、`←` `→` で桁を移動）。`t` でまとめて入力もできる。

## 6. 計算する

条件入力の**「計算する ▶」**、またはコマンドラインから：

```powershell
python run_project.py "C:\...\プロジェクト"
```

進捗ウィンドウが出る。ログはテキストにも残る。

### 6-1. 途中で出るメッセージの読み方

```
[loop_noredundancy] 経路 274666 本 → 受音 26446 本 / 却下 248220 本
```
バックトレースで成り立たなかった経路が却下された数。却下が多いのは異常ではない。

```
[procedure] 最大反射回数 nref=50 に達した経路がありますが、
            その時点で -59.2 dB まで減衰しているので残響時間には影響しません
```
**反射回数が足りているかの判定。**「影響します」と出たら反射回数を増やす。

```
[reverberation] ★ 曲率が 10% を超えたバンド（63Hz）は減衰が直線でないので
                そのまま信用しないこと。
[reverberation] ★ 非線形性 ξ（ISO 3382-2）が 10 を超えたバンド（…）は
                回帰直線に乗っていません。
```
★**このバンドの残響時間は読んではいけない**という合図（第 9 章）。

### 6-2. 出てくるファイル


## 7. 結果を 3D で見る

計算が終わると自動で開く。あとから見るときは条件入力の**「前回の結果を見る」**。

左パネル上端の**タブ**（`Tab` キーでも切り替わる）で 4 つを行き来する。

| タブ | 見えるもの |
|---|---|
| **音線** | 受音した経路がどう通ったか。到来時刻で色分け |
| **音粒子** | 音が広がっていく様子（アニメーション） |
| **虚音源** | 受音点から見た虚音源の位置。反射回数の**開始と終了**で絞る |
| **音圧分布** | `mode_shape.py` が作った断面（第 8 章。作っていなければタブは出ない） |

| キー | 動き |
|---|---|
| `Tab` | タブを切り替える |
| `space` | 音粒子の再生 / 停止 |
| `←` `→` / `Home` | 1 コマ戻す・進める / 先頭へ |
| `k` / `j` / `0` | 絞り込みの種類 / 基準点 / 絞り込みを解除 |
| `p` | 点を拾う（任意） |
| `z` `x` `c` `v` | 視点（上・正面・横・等角） |
| `r` | いま描いているものが全部入るように引く |
| `g` / `b` | 画像で保存 / **動画（MP4）で保存** |
| `q` | 閉じる |

- **音線の絞り込み**（`k`）は「なし / 近く / 方向 / 1 本」。
  方向は方位角・仰角のスピンボックスで指定する（0° = +X、反時計回り、仰角 0 が水平）。
  **出射方向で見る**（途中の向きだと反射のたびに変わって絞れない）。
- **動画は MP4（H.264）**。iPad でも再生・停止できる。
  **画面をそのまま「長さ」秒ぶん録ったもの**で、コマ数 = 再生速度 × 長さ。
  全部を早送りで見たいときは再生速度を上げる。
- **虚音源はカメラを合わせると室が点になる**（高次は室の外へ数 km 離れる）。
  `h` で室に寄り、`r` で全部が入る。
- **画角を保存 / 読込**（左の欄のボタン）＝ 条件を変えて計算し直しても同じ向きで見比べられる。

虚音源だけを単独で見る・図だけ書き出すこともできる（**計算はやり直さない**）。

```powershell
python view_images.py "C:\...\プロジェクト"
python view_images.py "C:\...\プロジェクト" --start 2 --end 2          2 回目反射のみ
python view_images.py "C:\...\プロジェクト" --start 1 --end 1 --fit room --screenshot 1次反射.png
```

## 8. 別ルートの道具（ふだんの出力には入らない）

いずれも**計算はやり直さない**（保存済みのパルス列や結果 CSV を読むだけ）。

### 8-1. 逆二乗則の評価（半無響室・無響室の確認）

```powershell
python inverse_square.py "C:\...\プロジェクト"
```

- 測線は**受音点のレイヤ**（`rec1` / `rec2` / `rec3`）で分ける。
- 基準の高さは**最小二乗**（傾きは −20log10 r に固定）。
- 許容偏差は **JIS Z 8732**（≦630 Hz ±2.5 / 800〜5000 Hz ±2.0 / ≧6300 Hz ±3.0）。
- **A（エネルギー和）と B（位相を含む複素和・参考）の両方**を出す。
  図では A が実線・B が細い破線。
  ★B の**山谷の位置は当てにならない**（反射の位相ずれを 0 と仮定しているため）。
  振れ幅の目安として見る。
- 図は測線ごとに 1 枚。上段が音圧レベルの偏移（半自由音場 Q=2 の理論線つき）、
  下段が偏差（許容偏差の上下限つき）。

報告書（Markdown ＋ PDF）まで作るなら：

```powershell
python report_inverse_square.py "C:\...\プロジェクト"
```

### 8-2. 伝達関数（干渉が見える形・モード分布の確認）

```powershell
python frequency_response.py "C:\...\プロジェクト" --low 20 --high 250 --step 0.5
```

剛な面（吸音を付ける前）の形状検討で使う。パルス列から複素和で H(f) を作る。

- ★**周波数分解能は「残した最長経路」で決まる**（Δf ≈ c / L_max）。
  刻みを細かくしてもそれ以上は出ない。図と端末に実力値が出る。
- 固有周波数（直方体とみなした目安）とシュレーダー周波数も出る。
- ★回折は解いていないので、**低域は「傾向を見る道具」**。

### 8-3. 音圧分布（モード形状）を断面で塗る

まず断面を決める。プロジェクト直下の `断面.json` に**1 枚 = 1 行**で並べる。

```powershell
python section.py "C:\...\プロジェクト" --create      雛形を作る
```

書き方は 2 通りだけ。

```json
{"name": "床上1.2m", "plane": "z", "at": 1.2}
{"name": "客席中心線", "through": [[2.0, 1.0], [2.0, 9.0]]}
```

`through` は**平面図に引いた測線を含む鉛直面**。傾いた面（点＋法線）は扱わない。

```powershell
python mode_shape.py "C:\...\プロジェクト" --frequency 40
python mode_shape.py "C:\...\プロジェクト" --sweep 20:100:5
```

- **やり方は 2 つ**（`--method`）。`box` は直方体の虚音源を式で並べる（なめらか）、
  `rays` は音線から拾った経路を使う（形は自由だがまだらになる）。`auto` は箱なら `box`。
- ★**完全に剛（α = 0）にしない**（既定 0.02）。減衰が無いと級数が収束せず、
  打ち切る位置で値が変わる。
- **色の基準は周波数ごとに全断面で共通**（断面どうしを比べられるように）。
- 切り口（境界面）が図に重なるので、什器・反射板の切り口も見える。
- 結果画面の**「音圧分布」タブ**でも見られる（チェックで複数の断面を同時に）。

## 9. 数値を信用してよいかのチェックリスト

計算が通っても、条件が足りていなければ数字は当てにならない。
**報告に使う前に、次を必ず確認すること。**

| # | 見るところ | 合格の目安 |
|---|---|---|
| 1 | **受音球の半径** | 半径を変えても残響時間が動かない（収束している） |
| 2 | **最大反射回数** | 「打ち切り時点で −○○ dB まで減衰しているので影響しません」と出ている |
| 3 | **非線形性 ξ**（`rt.csv`） | **ξ ≦ 10**（ISO 3382-2）。超えたバンドは回帰直線に乗っていない |
| 4 | **曲率 C**（`rt.csv`） | `(T30/T20 − 1)×100`。10% を超えたら減衰が 2 段階になっている |
| 5 | **容積** | `吸音率と理論値.csv` の容積が図面と合っている。自由端があれば「目安」 |
| 6 | **吸音率の種類** | 条件表「吸音率」シートの「種類」が正しい（垂直入射 / 残響室法） |
| 7 | **理論値との比** | `T30 / Eyring-Knudsen` が極端でない。極端なら 1〜3 を疑う |
| 8 | **面が拾えているか** | 総表面積・レイヤ別面積が図面と合っている |

★ 3・4 が引っかかっても、**必ずしも計算ミスではない**。小さい室・平行面・面ごとに
吸音率が大きく違う場合は、**減衰が本当に 2 段階になる**ので曲率が出るのが正しい
（EDT と T30 の差にも表れる）。そのときは「拡散音場を前提にした残響時間という指標が
そもそも合っていない」と読む。

## 10. よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 「面が 1 枚も読めません」 | DXF が REGION / 3DSOLID。`python dxf_faces.py <DXF>` で面に変換する |
| 「吸音率が未指定のレイヤ → 0.1 を使用」 | 条件表でそのレイヤに材料番号を入れていない |
| 残響時間が理論値よりかなり短い | 受音球の半径か最大反射回数の不足（第 9 章の 1・2） |
| 音圧レベルが 30 dB ずれる | 気圧に Pa を入れている。**kPa**（101.325）で入れる |
| 統計残響式が出ない | モデルが閉じておらず容積が決まらない。条件入力の「室容積」に入れる（床面積 × 天井高で可） |
| 「面を確認」のボタンが見えない | ウィンドウが小さい。横に伸ばすか最大化する |
| 法線の反転が効かない | DXF を描き直して面数が変わった。`normals.json` は使われず警告が出る。貼り直す |
| STI が出ない | 1/3 オクターブで回している。**STI はオクターブ 125〜8k が前提**（IEC 60268-16）なので飛ばす |
| 3D 画面が落ちる・真っ黒 | GPU の都合。`view_model.py`（HTML 版）で代用できる |

## 11. 覚えておくと早いこと

- **同じ計算を条件だけ変えるなら一括で回す。**2 件目以降は経路を使い回すので速い。
- **図だけ描き直したい**ときは「前回の結果を見る」（`run_project.py --redraw`）。
  音線追跡はやり直さないので数秒で終わる。
- **画角を保存しておく。**条件を変えると画面は開き直しになるので、
  保存しておかないと毎回向きが変わって絵を並べても比べられない。
- **3D 画面から撮った画像・動画は `図/画面/` に入る。**計算し直しても消えない。
- **1/3 オクターブでも回せる**（`band_width` = `1/3`、`band_start` で最低バンドを指定）。
  ただし STI は出ない。
- **インパルス応答の図は最大値で正規化してある。**絶対振幅の校正が未了なので、
  そのままの値には意味が無い。
