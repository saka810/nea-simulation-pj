# DIRAC 7 測定マニュアル（インストール・セッティング・残響時間・STI）

B&K（HBK）の室内音響測定システム **DIRAC 7（Type 7841）** と、同時に導入した機材で
**残響時間**と**音声明瞭度（STI）**を測るための手順書。

対象機材：

| 機材 | 型番 | 役割 |
| --- | --- | --- |
| DIRAC 7 | Type 7841 | 測定・解析ソフト（Windows）。インパルス応答を測り、そこから全パラメータを出す |
| スマートパワーアンプ | HBK 2755 | 12 面体を鳴らすアンプ。**USB でサウンドデバイスにもなる**（マイク入力つき）。Wi-Fi 遠隔操作可 |
| 騒音計 | HBK 2255 | 校正済みのマイク。**Wi-Fi で DIRAC のマイクになる**（要 BZ-7451） |
| エコースピーチ音源 | Type 4720 | **人の口を模した指向性と音声スペクトル**を持つ校正済み音源。STI 用 |
| 12 面体スピーカ | OmniPower Type 4292-L など | 無指向性音源。ISO 3382 の残響時間測定用 |
| パワードスピーカ | MACKIE | 汎用の音源。手軽な残響測定・PA 系の検討用（無指向性ではない） |

> **画面の文言について** — 本書は DIRAC 7.x（7.0 以降）の画面を前提に書いてある。
> バージョンによってメニュー名が少し変わることがあるので、迷ったら `Help`（F1）の
> コンテキストヘルプを見ること。

---

## 0. 全体像

測定の骨格は、どの測り方でも同じ。

```
  (1) 音源から既知の信号を出す            (2) マイクで受ける
      （スイープ / MLS / 変調ノイズ）             ↓
  (3) DIRAC が逆畳み込みしてインパルス応答（IR）にする
      ↓
  (4) IR から全パラメータを計算（残響時間・明瞭度・STI…）
```

DIRAC の考え方は「**まずインパルス応答を 1 本きれいに録る。指標は後からいくらでも出る**」。
つまり現場でやることは、**良い IR を取ること**にほぼ尽きる。良し悪しの物差しは INR（後述 3.5）。

### 0.1 3 つの構成パターン

| | 構成 | サウンドデバイス | 使いどころ |
| --- | --- | --- | --- |
| **A** | PC —(USB)— **2755** — 12 面体。マイクは 2755 の入力へ | 2755（USB オーディオ） | **標準構成。**同期測定になり音源‑受音点距離が自動で出る。まずこれ |
| **B** | PC 〜(Wi-Fi)〜 **2755** — 12 面体。PC 〜(Wi-Fi)〜 **2255** | 無線 | 大空間・PC を持ち歩けない場合。ケーブル敷設が要らない。**非同期**（距離は出ない） |
| **C** | PC —(USB オーディオ I/F)— **MACKIE**。マイクは I/F または 2755 経由 | ZE-0948 等の USB I/F、または 2755 | 12 面体を持ち出せないとき、PA 系の検討 |

**同期（synchronous）と非同期（asynchronous）** は必ず区別すること。

- **同期** … 再生と録音が同じサンプルクロック（＝同じ USB デバイス）。
  **音源‑受音点距離が自動で測れる**ので、ISO 3382-3 や G（ストレングス）に必要。
- **非同期** … Wi-Fi 経由や、Echo 4720・CD などの外部音源。距離は出ないが
  MLS なら DIRAC が時計のずれを吸収して IR を取り出せる（DIRAC 4 以降の機能）。

## 1. インストール

### 1.1 PC の要件

- Windows 11 / 10（8, 7, Vista も可）
- CPU 1 GHz 以上、RAM 2 GB 以上、空きディスク 500 MB 以上
- .NET Framework 4.5
- 画面 1024×600 以上（1280×768 以上を推奨）
- **フルデュプレックスのサウンドデバイス**（Core Audio / WASAPI か ASIO 対応）。
  22.05 / 44.1 / 48 / 65 / 96 / 192 kHz

### 1.2 DIRAC 7 本体を入れる

1. 納品された USB メモリ（または B&K のダウンロードページ）の `Dirac7Setup.exe` を実行する。
2. 管理者権限で、既定の場所にインストールする。
3. **ドングルはまだ挿さない**（先にドライバを入れたほうが確実）。

### 1.3 ★ドングル（HASP キー）の設定 — ここが一番つまずく

DIRAC のライセンスは **Sentinel HASP の USB ドングル**が持っている。
「ドングルを挿した PC でなら動く」ので **PC を選ばず使える**。
そのぶん**ドングルを失くすとライセンスごと失う**ので、持ち出し管理を決めておくこと。

手順：

1. **HASP ランタイム（ドライバ）を入れる。**
   製品 USB / CD に入っているドライバは**古くて Windows 10/11 で動かないことがある**。
   その場合は Acoustics Engineering のサポートページ（`acoustics-engineering.com` の
   HASP drivers）から新しいランタイムを落として入れる。
   zip を展開し、PowerShell を**管理者として**開いて実行：

   ```
   .\haspdinst -i -ld
   ```

2. ドングルを USB に挿す。**ドングルの赤い LED が点く**ことを確認。
3. `デバイスマネージャー` → `ユニバーサル シリアル バス コントローラー` に
   **`Sentinel HASP Key`** が出ていることを確認。
4. DIRAC を起動し、`Help` → `About` を開いて **`Alt` + `F10`** を押す。
   ライセンスユーティリティが開き、`Installed Licenses` に **`7841 7.0`** のような
   エントリが見えれば OK。
5. さらに確認したいときは、ブラウザで `http://localhost:1947`
   （Sentinel Admin Control Center）を開くと、ランタイムのバージョンと認識中の
   ドングルが見られる。

> **★ドングルが見えないときの順番** — ①LED を見る（消えていればハード側）→
> ②デバイスマネージャー → ③ランタイムのバージョン（`localhost:1947`）→
> ④USB ハブを外して本体に直挿し。ノート PC の省電力設定で USB が切られることもある。

> **参考：ノードロック版・フローティング版** — DIRAC 7 には
> `7841-N`（ノードロック＝PC 固定）と `7841-F`（フローティング＝社内で共有）もある。
> 本 PJ はドングル版なので、上の手順で運用する。

### 1.4 起動確認

ドングル無しでも DIRAC は**デモ版として起動する**（保存や一部機能が制限される）。
「起動はするのにライセンスが無い」と言われたら 1.3 を疑う。

### 1.5 HBK 2255（騒音計）を DIRAC のマイクにする準備

2255 を**無線マイク**として使うには次が要る。

- **`BZ-7451` Analysis-quality Audio ライセンス**が 2255 に入っていること（必須）
- ファームウェアは標準の `FW-2255-000`（型式承認品）で可
- 2255 と PC が**同じ Wi-Fi** にいること（または 2255 のホットスポットに PC がつながること）

準備：

1. 2255 の Wi-Fi を有効にし、ネットワーク（または自身のホットスポット）に接続する。
2. **音響校正器（Type 4231 など）で 2255 を校正する。**
   ここで校正しておけば、DIRAC 側の入力レベル校正がそのまま生きる（2.2 参照）。
3. 電池残量を確認する（無線ストリーミングは電池を食う）。

### 1.6 Echo Speech Source Type 4720（STI 用音源）の準備

- 単 3 電池 4 本で動く（基準レベルで最大 24 時間、+12 dB の高レベルで約 8 時間）。
  外部電源 `ZG-0864` もある。
- **本体に校正済みの信号が 5 つ入っている。**無響室で 1 台ずつ校正されており、
  出力スペクトルは **±1 dB**、基準レベルは **1 m で 60 ±1 dB(A)**。

  | 信号 | 中身 | 用途 |
  | --- | --- | --- |
  | Voice | 男声のスピーチ | PA の音量を「ふつうの声」に合わせるための参照 |
  | Continuous 60 | 連続ピンク MLS・60 dB(A) | 暗騒音が低く残響が長い部屋 |
  | Continuous 72 | 連続ピンク MLS・72 dB(A) | 騒がしい部屋 |
  | Intermittent 60 | MLS ＋ 同じ長さの無音・60 dB(A) | **IR と暗騒音を一度に測る**（推奨） |
  | Intermittent 72 | 同上・72 dB(A) | 同上、騒がしい部屋 |

- 三脚に載る。**口の高さ**（立位 1.5 m／座位 1.2 m 前後）に置く。
- DIRAC 7 では **Echo の信号を DIRAC 側から再生することもできる**（`Voice` ボタン）。
- 4720 が無くても、Acoustics Engineering が配布している **Echo ファイル**（同じ信号の音源）を
  スマホや CD で再生して PA に流す使い方もできる。ただし**レベルとスペクトルの校正が
  効かない**ので、STI の絶対値を出す用途では 4720 を使うこと。

### 1.7 HBK 2755（パワーアンプ）の準備

- **背面の電圧セレクタが日本の 100 V に合っているか**を、電源をつなぐ前に必ず確認する。
- 12 面体（4292-L）は **6 Ω・speakON 4 極（1+ / 1−）**。付属のスピーカケーブルで
  アンプの出力へ。**出力モードは `Bridge`**（`Output` > `Output mode` > `Bridge`）。
- ★**ゲイン（減衰量）は電源投入時に −30 dB に戻る。**測定のたびに設定し直す。
  設定は**スピーカケーブルを外した状態**でやると安全。
- ★**小さいスピーカをつなぐときは `Output` > `Gain limit` を必ず設定する。**

  | Gain limit [dB] | 6 Ω への最大出力 |
  | --- | --- |
  | 0 | 300 W |
  | −10 | 30 W |
  | −20 | 3 W |
  | −30 | 0.3 W |

  ★この制限も**電源を入れ直すと解除される**。
- 誤操作を防ぐには `Output` > `Gain lock` > `Enabled`（つまみをロック）。
- Wi-Fi を使うなら：`Network` > `Webserver` > `Enabled`、`Network` > `Wi-Fi mode` >
  `Hotspot`（既定 SSID は `HBK2755-<製造番号>`、既定パスワード `hbk2755pwd`。**変更すること**）
  または `Station`（社内 LAN に参加）。

## 2. セッティング（測定前の設定）

### 2.1 サウンドデバイスを選ぶ

`Setup` → `Sound Device…` を開く。

**構成 A（2755 を USB でつなぐ／推奨）**

1. 2755 と PC を USB-C ケーブルでつなぐ。2755 が「パワーサウンドデバイス」になる。
2. 入力・出力とも `core: … (USB AUDIO CODEC)` のような 2755 のデバイスを選ぶ。
3. マイクは 2755 の前面入力へ（XLR / BNC / TRS）。`Input` メニューで
   XLR ゲイン 0 / 10 / 20 / 30 dB、ファンタム 48 V、IEPE を切り替える。
   ★**ハムが出るときは不平衡の BNC ではなく平衡の XLR を使う。**
4. **設定に名前を付けて保存する**（DIRAC 7 はデバイス構成を測定セットアップの中に
   保存できる）。現場で選び直す手間が減る。

**構成 B（Wi-Fi）**

1. `Setup` → `Sound Device…` で、出力に **`tcpip: HBK 2755`** を選ぶ。
   入力は 2255（無線マイク）を選ぶ。
2. 名前を付けて保存し、`Measurement` ウィンドウの **`Device` タブ**で
   その構成が選ばれていることを確認する。
3. **新しい機器が見つかると DIRAC が接続の可否を聞いてくる**（初回だけ）。
   `Measurement` ウィンドウの **`Wireless` タブ**に機器名と製造番号が並ぶ。
4. ★**同じ無線に他人の 2755 / 2255 がいると混ざる。**`Access Control` で
   見つける機器を絞る。複数台つながっていても、有効なのは常に 1 台（アイコンが点灯）。
5. ★**見つからないとき**：Wi-Fi が混んでいると発見に失敗する。2755 を再起動するか、
   `Network` > `Info` で IP アドレスを見て手入力する。

**構成 C（USB オーディオ I/F ＋ MACKIE）**

1. `ZE-0948` などの USB オーディオ I/F を挿す（ドライバ不要のクラスコンプライアント品）。
2. ライン出力 → MACKIE のライン入力、マイク → 入力へ。
3. **2755 を持っているなら、2755 を USB サウンドデバイスにして
   その「ライン出力」を MACKIE に入れるのが楽**（マイクのファンタム電源も 2755 が出せる）。

### 2.2 校正（3 種類ある。目的で使い分ける）

| 校正 | 何のため | いつ要るか |
| --- | --- | --- |
| **入力レベル校正**（Input level calibration） | 絶対音圧レベルを出すため（Leq, Lp,A,S, 暗騒音） | **STI を出すなら必須。**残響時間だけなら不要 |
| **音源‑受音点距離校正**（Source-receiver distance） | 距離を自動で出すため | 同期測定のとき。ループバックケーブルで測る |
| **システム校正**（System calibration） | ストレングス G と関連量のため | G / ISO 3382-3 をやるとき。残響室か自由音場で |

**入力レベル校正の手順**

1. マイクに音響校正器（Type 4231：1 kHz・94 dB）をかぶせて鳴らす。
2. DIRAC の校正ダイアログでその値（94 dB）を入れて校正する。
3. **2255 を無線マイクとして使う場合**は、2255 側で校正しておけばその感度が DIRAC に渡る。
   どちらで校正したかを記録に残すこと。
4. ★VU メーターの数字が**赤い**のは「未校正で相対 dB 表示」の意味。
   校正が効いていれば絶対値表示になる。

**距離校正の手順（ループバック）**

1. サウンドデバイスの出力と入力を直接ケーブルで結ぶ。
2. `Sound Device Setup` の距離校正ボタンを押す。
   これで機器内部の遅れ（ドライバのバッファ等）が差し引かれ、
   IR の立ち上がり時刻がそのまま音源‑受音点距離になる。
3. ★ループバックが使えない構成では、**既知の距離**（例：1.00 m）に
   マイクとスピーカを置いて測る方法でもよい。
4. 補正しきれない一定のずれは `Setup` > `Options` の `System delay`（サンプル数）で入れる。

### 2.3 測定セットアップを保存する

DIRAC には ISO 3382-1/-2、ISO 3382-3、STI 用などの**プリセット**がある。
現場で作り込むのではなく、**事務所で作って保存しておく**こと。
デバイス構成も一緒に保存されるので、現場では選ぶだけになる。

## 3. 残響時間の測定

### 3.1 規格が要求するもの（ISO 3382-2）

| | Survey（簡易） | Engineering（実用） | Precision（精密） |
| --- | --- | --- | --- |
| 音源‑マイクの組合せ | 2 | **6** | 12 |
| 音源位置 | 1 以上 | 2 以上 | 2 以上 |
| マイク位置 | 2 以上 | 2 以上 | 3 以上 |
| 断続騒音法の減衰回数／位置 | 1 | 2 | 3 |
| 周波数範囲（オクターブ） | 250 Hz〜2 kHz | **125 Hz〜4 kHz** | 125 Hz〜4 kHz（1/3 オクターブなら 100 Hz〜5 kHz） |
| 想定精度 | 10 % 以内 | 5 %（1/3 oct. は 10 %） | 2.5 %（1/3 oct. は 5 %） |

**★音源の無指向性が要求されるのは Precision だけ**（ISO 3382-1 A.3.1 の指向性規定）。
**Survey と Engineering には指向性の規定が無い。**
つまり MACKIE のようなふつうのスピーカでも、Engineering 等級までは規格の枠内で測れる
（後述 3.4 の注意は守ること）。

インパルス応答法（DIRAC の測り方）は断続騒音法と**期待値が同じ**と規格に明記されている。
1 組合せあたり 1 回で足りるので、Engineering なら **6 回**の測定で済む。

### 3.2 位置の決め方

- **音源位置**：その部屋の実際の使われ方に沿った位置（教室なら教壇、ホールなら舞台）。
  小さい部屋や「ふつうの位置」が無いときは**部屋の隅**に置く。
- **マイク位置どうし**：半波長以上（**目安 2 m**）離す。
- **マイクと反射面（床を含む）**：1/4 波長以上（**目安 1 m**）離す。
- **対称な位置は避ける**（同じモードばかり拾う）。
- **音源とマイクの最小距離**：直接音が効きすぎないように、

  $$ d_{\min} = 2\sqrt{\frac{V}{cT}} $$

  V は室容積 [m³]、c は音速 [m/s]、T は予想残響時間 [s]。
  例：V = 1000 m³、T = 1.0 s、c = 343 m/s なら d_min ≈ 3.4 m。
- **人は入れない**（2 人までは無人とみなしてよい）。
- **精密測定では温度と湿度を測る。**ただし 2 kHz で T < 1.5 s、4 kHz で T < 0.8 s なら
  空気吸収は無視できるので不要。

### 3.3 手順：12 面体スピーカ（4292-L ＋ 2755）を使う場合

**準備**

1. 12 面体を三脚に載せる（高さ 1.3〜2.1 m の範囲で調整可）。床置きもできる（ゴム脚）。
2. 2755 の**出力モードを `Bridge`** にし、speakON ケーブルで 12 面体へ。
3. 2755 と PC を USB でつなぐ（構成 A）。マイクを 2755 の入力へ。
4. **ゲイン（減衰量）は −30 dB から始める。**

**DIRAC の設定**

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| Stimulus | **Exponential Sweep（125 Hz〜4 kHz）** | ISO 3382-1/-2 用のプリセット。歪みに強く、MLS より高い出力を出せる |
| 長さ | 予想残響時間より十分長く（**目安 T の 2 倍以上**、最低でも 2〜3 秒） | IR が測定区間に収まらないと減衰が読めない |
| Pre-average | 1（暗騒音が高ければ 2, 4, 8…） | 倍にするごとに INR が最大 3 dB 改善 |
| Receiver | Single omnidirectional microphone | 残響時間だけならこれで足りる |
| Intermittent | 暗騒音も同時に測りたいときは ON | 1 回で IR ＋ 暗騒音が録れる |

**測る**

1. `Measure` ボタンで測定ウィンドウを開く。
2. **`Test` を押して信号を出しっぱなしにし、レベルを合わせる。**
   - 2755 の**レベル表示の黄／赤の境目（クリップ）を越えないこと。**
     IR 測定では歪みは致命的。
   - DIRAC 側の録音レベルは、**メーターが緑の一番上まで届く**くらい（12 dB のヘッドルーム）。
3. `Start` で測定。IR が表示される。
4. 3.5 の品質チェックを**その場で**やる。だめならレベル・長さ・Pre-average を直して録り直す。
5. 保存する（`.wav`。位置名を入れておくと、後で自動的にファイル名になる）。
6. マイク位置を移して繰り返し、音源位置も変えて、**3.1 の表の組合せ数を満たす**。

**★測定中に守ること**

- 部屋の状態を変えない（人の移動、空調のオンオフ、扉の開閉、温湿度の変化）。
  DIRAC の測定は「部屋が時間的に変わらない」ことが前提。
- **マイクの近く・音源の近く・強い反射の経路上を人が横切らない。**

### 3.4 手順：MACKIE パワードスピーカを使う場合

12 面体を持ち出せないときの構成。**Survey / Engineering 等級としては規格内**だが、
次の点を守る。

**つなぎ方**

```
  PC ──(USB)── 2755 ──[ライン出力]── MACKIE のライン入力（XLR / TRS）
                  └──[入力]── マイク（ファンタム 48 V も 2755 から出せる）
```

★**MACKIE を 2755 のスピーカ出力につながない**（パワードスピーカは自分でアンプを持っている）。
2755 を使わず、USB オーディオ I/F のライン出力から直接 MACKIE に入れてもよい。

**MACKIE 側の設定**

- **DSP・EQ・「Contour」「Boost」などの音作りは全部オフ／フラット**にする。
  残響時間は帯域ごとの減衰を見るので、勝手な補正が入ると帯域が偏る。
- **リミッタが働くレベルまで上げない**（歪む＝IR が汚れる）。
  本体のクリップ LED が光らない範囲で使う。
- ハイパスフィルタが入っている機種は、**低域が出ないことを承知しておく**
  （63 Hz・125 Hz の残響時間が測れないことがある）。

**DIRAC 側の設定（12 面体との違い）**

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| Stimulus | **必ず Exponential Sweep**（MLS は使わない） | ★e-sweep は**非線形歪みが IR の外に出る**ので分離できる。DIRAC 7 は INR や RT の計算で歪み成分を自動的に除く。MLS だと歪みが IR 全体にばらまかれる |
| 音源の向き | **部屋の隅／斜め上に向ける。**壁や聴衆に直接向けない | 指向性があるので、直接音ばかり強く入ると初期減衰が偏る |
| 音源位置 | **12 面体のときより多めに取る**（最低 2、できれば 3 以上） | 指向性の偏りを位置の数で均す |

**★結果に必ず書き添えること** — 「無指向性音源を用いていない（ISO 3382-2 の
Survey / Engineering 等級。Precision の指向性要求は満たさない）」。
後から見た人が精度を誤解しないようにする。

### 3.5 測定の良し悪しを判定する（INR）

**INR（Impulse response to Noise Ratio）** ＝ IR のピークと、尾の暗騒音レベルの比。

| 目的 | 必要な INR |
| --- | --- |
| T20 を出す | **35 dB 以上** |
| T30 を出す | **45 dB 以上** |

判定は 3 つの方法を併用する。

1. **IR の絵を見る。**尾が平らで、測定区間の中に収まっていること。
   - 尾が下がり切らずに床が見える → 暗騒音が高い／出力が足りない
   - 尾が切れている（右端まで減衰が続いている）→ **信号長が足りない**
2. **INR の数字を見る**（Levels テーブル）。
   ★INR の頭に **`>`** が付いていたら「信号長が短くて暗騒音が測れず、下限値しか言えない」印。
   信号を長くする。
3. **聴く。**再生ボタンで IR を鳴らす。見た目では分からない障害が分かる。

**INR が足りないときの手当て（効く順）**

1. 出力を上げる（歪まない範囲で）
2. MLS を使っていたら **sweep に替える**（同じ歪みまでで 6 dB ほど稼げる）
3. **Pre-average を倍にする**（1 回の倍加で最大 +3 dB。ただし暗騒音に対してのみ有効で、
   歪みや部屋の時間変化には効かない）
4. 暗騒音そのものを下げる（空調停止、時間帯を変える）

### 3.6 結果を見る・出す

- `Reverberation` の計算画面で **EDT / T20 / T30** の周波数特性が見られる。
- `Parameter` メニューの **ISO 3382 テーブル**に規格の全パラメータが並ぶ。
- **複数ファイルをグループにまとめると、平均・標準偏差・最小・最大が出る。**
  音源位置ごとにグループを分けると比較しやすい。グループはプロジェクトとして保存できる。
- 出力：グラフ・表ともクリップボード／印刷／**ASCII（テキスト）書き出し**。
  ODEON 形式でも出せる。報告書には表をテキストで出して Excel で整形するのが早い。

## 4. STI（音声明瞭度）の測定

### 4.1 直接法と間接法

IEC 60268-16 は STI の測り方を **2 通り**定めている。DIRAC 7 は**両方できる**。

| | **間接法**（インパルス応答法） | **直接法**（変調ノイズ法） |
| --- | --- | --- |
| 何を出す | MLS / スイープ | **変調された騒音**（STIPA 信号） |
| 何をする | IR から MTF を計算（Schroeder の関係） | 受けた信号の変調度を直接測る |
| 時間 | **速い**（1 回数十秒） | STIPA で**最低 15 秒**×繰り返し。フル STI なら 15 分級 |
| 診断性 | **高い**（変調周波数の連続 MTF が見える。反射・エコーの原因まで追える） | 低い（規定の点のみ） |
| 弱点 | 系が**線形・時不変**である必要（圧縮やノイズゲートの入った PA には向かない） | 非線形な系でも測れる |

**使い分けの原則**

- **室の音響（肉声・拡声なし）を評価する** → **間接法**。速くて情報量が多い。
- **PA・非常放送設備を、実運用の状態で検査する**（リミッタ・コンプレッサ・
  レベル制御が入っている）→ **直接法（STIPA）**。
- **両方測って突き合わせる**のが理想（DIRAC 7 なら同じ機材・同じ部屋・同じ条件で
  ほぼ同時に比較できる）。

> **STI / STIPA / RASTI の関係** — STI が本体（125 Hz〜8 kHz の 7 オクターブ、
> 変調周波数 0.63〜12.5 Hz）。**STIPA** はそれを PA 用に簡略化したもので、
> 現行規格が**ほぼすべての場面で推奨する指標**。**RASTI** は 1985 年に B&K が作った
> 簡易版で、**現在は STIPA に置き換えられている**（新規案件では使わない）。

### 4.2 前提条件（どちらの方法でも）

- ★**入力レベル校正が済んでいること**（2.2）。STI は暗騒音の影響を含む指標なので、
  絶対レベルが分からないと正しく出ない。
- **暗騒音を測ること。**運用時の状態（空調 ON など）で測る。
- 受音マイクは**無指向性**。
- **測定位置**は評価したい聴取位置（座席、居室内の代表点、放送を聞かせたい範囲）。
  1 室で複数点を測り、ばらつきを見る。

### 4.3 間接法：肉声（拡声なし）の STI を Echo 4720 で測る

**これが「話者の声が届くか」を評価する標準的なやり方。**

1. **4720 を話者位置に置く。**三脚で口の高さ（立位 1.5 m／座位 1.2 m 前後）、
   評価したい向き（聴衆側）に向ける。
   ★4720 は **IEC 60268-16 が規定する口の指向性と音声スペクトル**を持つ。
   ふつうのスピーカで代用すると、この指向性が違うので結果が変わる。
2. **マイクを受音位置に置く**（2255 なら無線でよい）。
3. DIRAC の測定セットアップで **`ECHO Speech Source`** を選ぶ。
   ★これを選べば**他の設定は要らない**（信号の素性を DIRAC が知っている）。
4. 4720 の信号を選ぶ。
   - **既定は `Intermittent 60`**（MLS ＋ 同じ長さの無音）。
     **1 回の測定で IR と暗騒音の両方が別チャンネルに録れる**ので、
     暗騒音補正が正しく効く。まずこれを使う。
   - 暗騒音が高い部屋では `Intermittent 72`（+12 dB）。
   - ★目安として `SNR × RT < 120 dB·s` の部屋なら intermittent で足りる。
     暗騒音が低く残響が非常に長い部屋では `Continuous` を使う。
5. 4720 で信号を再生し、DIRAC で `Start`。
   ★**非同期測定**（4720 は PC と時計を共有していない）だが、
   MLS なので DIRAC が時計のずれを吸収する。
6. `Speech` テーブルで **STI・MTI・音声レベル・暗騒音レベル**を確認する。

**★なぜ 4720 を使うと楽か** — MLS 信号に**出力レベルが符号化されている**ので、
DIRAC が音源レベルを自動で知り、STI の計算を正しく補正する。
イコライザで音声スペクトルを作る必要も、レベルを測り直す必要もない。

### 4.4 間接法：PA・放送設備の STI

拡声系の評価では、**部屋のスピーカ（PA のスピーカ）そのものが音源**になる。

1. まず **4720 の `Voice`（男声）を鳴らして、PA の音量を「ふつうの声」のレベルに合わせる**
   （1 m で 60 dB(A) 相当）。運用時の設定に合わせるのが目的。
2. 測定信号を PA に入れる。入れ方は 2 通り。
   - **直接注入**：DIRAC（または 2755）の出力を PA のライン入力へ。
     系のマイクを通らないぶん素性がはっきりする。
   - **音響的に入れる**：4720 を PA のマイクの前に置く。
     系のマイクの特性も含めて評価できる。
3. 受音位置でマイクを構え、間接法で測る。
4. ★**PA にリミッタ・コンプレッサ・オートレベル・ノイズゲートが入っている場合、
   間接法は使えない**（線形時不変でないため）。この場合は直接法（4.5）へ。

### 4.5 直接法：STIPA（変調ノイズ）

DIRAC 7.1 以降で使える。

**信号の中身**：7 つの半オクターブ幅の搬送ノイズを、それぞれ 2 つの低周波で変調したもの。

**手順**

1. 測定セットアップで **STIPA（変調ノイズ法）**を選ぶ。
   - 音源スペクトルは**ピンク／ホワイト**が選べる。
   - **音源レベルは 1 m で 60 dB(A)** を前提とする設定になっている。
2. **信号長は最低 15 秒。**実務では 15〜30 秒を 2〜3 回繰り返し、平均を取る。
3. 音源：
   - 肉声の評価 → **4720 の STIPA 信号**（本体に入っている）
   - PA の評価 → PA から STIPA 信号を流す（直接注入または CD / プレーヤ）
4. `Speech` テーブルに **MTF・MTI・音声レベル・暗騒音レベル**が出る。

**★直接法の注意**

- 測定中に**部屋の音環境を変えない**（人の出入り、突発音）。突発音が入ったら測り直す。
- 変調を壊す機器（極端な圧縮、遅延の揺らぎ）があると値が下がる。
  **それが実際の性能**なので、下がったからといって間接法に逃げないこと。
- 携帯型 STIPA メータと比べるときは、**音源レベルと暗騒音の扱いが揃っているか**を確認する。

### 4.6 暗騒音の扱い

STI は「暗騒音にどれだけ埋もれるか」を含む指標なので、暗騒音の扱いが結果を左右する。

- **intermittent 信号を使えば、IR と暗騒音を 1 回で測れる**（最も確実）。
- 別に測る場合は、**運用時の状態**で暗騒音を測って DIRAC に入れる。
- **DIRAC では音声レベルと暗騒音レベルを手で入れて再計算できる。**
  「空調を止めたら STI がどこまで上がるか」といった検討がその場でできる。
- **SNR が高い＝暗騒音の影響が小さい。**このとき STI が低ければ、原因は**残響**。

**★MTF グラフで原因が分かる**（DIRAC の強み）

| MTF の形 | 原因 |
| --- | --- |
| 変調周波数によらず**平ら** | **暗騒音**が支配的 |
| 変調周波数とともに**単調に下がる** | **残響**が支配的 |
| いったん下がってまた**上がる** | **エコー**（特定の強い反射） |

対策の打ち手（吸音か、遅れ反射の処理か、騒音源対策か）がここで決まる。

### 4.7 評価

DIRAC は STI を数値と評語（`Bad` 〜 `Excellent`）で出す。

| STI | 評語 |
| --- | --- |
| 0.00 – 0.30 | Bad |
| 0.30 – 0.45 | Poor |
| 0.45 – 0.60 | Fair |
| 0.60 – 0.75 | Good |
| 0.75 – 1.00 | Excellent |

- **非常放送・避難誘導放送は STI ≧ 0.50 が目安**（ISO 7240-19 / IEC 60849 系）。
- ★IEC 60268-16 は版によって**区分の呼び方が違う**（2011 年版以降は
  `A+`〜`U` の等級表記もある）。報告書には**どの版のどの区分を使ったか**を明記する。
- 男声・女声で STI が変わる（DIRAC は両方出せる）。**どちらで評価したかを書く。**

### 4.8 MACKIE を STI に使えるか

| 用途 | 可否 |
| --- | --- |
| **肉声（話者）の STI** | ★**不可**（結果が別物になる）。IEC 60268-16 の口の指向性・音声スペクトルを満たさない。**4720 を使うこと** |
| **PA の STI** | 可。ただし「MACKIE が評価対象の PA スピーカである」場合に限る |
| 予備調査・傾向を見る | 可。ただし**絶対値としては報告しない** |

## 6. トラブルシューティング

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| DIRAC がデモ版として起動する | ドングルが認識されていない | 1.3 の手順。LED → デバイスマネージャー → HASP ランタイム更新 |
| **IR の先頭に鋭いスパイクが出る** | **クロストーク**（ケーブルの引き回し・インピーダンス不整合） | 出力と入力のケーブルを離す。取り切れないときは `Setup` > `Options` の `Minimum Source-Receiver distance` に適当な値を入れて無視させる（★DIRAC を閉じると 0 に戻る） |
| **IR に無数のスパイクが乗る**（MLS のとき） | どこかで**過大入力**（クリップ） | 入力ゲインか音源レベルを下げる。★MLS ではクリップが「潰れ」ではなくスパイクとして出る |
| IR の尾が下がり切らない | 暗騒音が高い／出力不足 | 3.5 の手当て |
| IR が右端まで続いている | **信号長が短い** | Stimulus の長さを伸ばす（予想 RT の 2 倍以上） |
| INR に `>` が付く | 信号長が短く暗騒音が測れていない | 同上 |
| **スイープの末尾に小さな塊が出る** | スピーカの**非線形歪み** | 出力を下げる。残す場合は `Edit` > `Delete` で先頭前と尾を切って使える（DIRAC 7 は歪み成分を自動で除外もする） |
| 50 / 60 Hz のハムが乗る | ケーブル長・アースループ | マイクケーブルを電源から離す。不平衡の BNC でなく **平衡の XLR 入力**を使う。★高調波が無ければ「たまたま 50 Hz の室モード」なので機器の問題ではない |
| Wi-Fi で 2755 / 2255 が見つからない | 無線が混雑 | 2755 を再起動、または `Network` > `Info` の IP を手入力。`Access Control` を確認 |
| **`Test` を押しても音が出ない**（Wi-Fi 経由） | ★**アンプが過大入力で保護に入った**（例：−6 dB の MLS）。DIRAC はこれを検知できず、Test は押されたままに見える | アンプの表示（警告マーク）を見る。出力レベルを下げる |
| 測定ごとに結果がばらつく | 部屋が時間的に変化（人の移動・空調・温湿度） | 3.3 の「測定中に守ること」。Pre-average を上げても直らない種類の誤差 |
| チャンネルが入れ替わっている | ケーブルの挿し違い | 2 チャンネルで測ってみる。ch2 のほうが良い IR なら入れ替わり |
| STI が異様に高い／低い | 入力レベル校正をしていない／暗騒音の設定が違う | 2.2 の入力レベル校正をやり直す。VU の数字が赤（未校正）でないか見る |
| 2755 の音が小さい／出ない | ★**電源投入で減衰が −30 dB に戻る。Gain limit も解除される** | 1.7 を確認。`Gain lock` も見る |
