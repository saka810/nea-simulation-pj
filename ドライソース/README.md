# ドライソース

可聴化（`geosim/auralize.py`）で畳み込む元の音。無響室で録った音源です。

## 自分の音源を足すには（ここに置けば一覧に並びます）

| 置き場 | 使いどころ |
|---|---|
| **`nea-simulation-pj/ドライソース/`**（このフォルダ） | みんなで使う音源。★**画面へ落とした音もここに保存されます** |
| `<プロジェクトフォルダ>/ドライソース/` | その案件だけで使う音源（一覧に「この案件」と出ます） |

- 置き方は 2 通り：**① このフォルダにファイルを入れる**（画面の「ドライソースのフォルダを開く」で開けます）
  **② 可聴化の画面へファイルを落とす**（このフォルダに保存され、すぐ選ばれます。同じ名前で中身が違えば `名前_2.wav` にします。上書きはしません）
- 画面を開いたまま①で足したときは、「音源」の横の **「一覧を更新」** を押すと並びます
- **中にフォルダを作って分けてもよい**（`ドライソース/坂吉/声.wav` → 一覧には `坂吉/声` と出ます）
- 形式は wav / mp3 / flac / ogg / m4a。名前はファイル名がそのまま出ます
- ★Git には入りません（下記）。**別の端末でも使いたい音源は、OneDrive の原本フォルダにも入れておいてください**

★**音声ファイル本体は Git に入れていない**（このリポジトリは public のため。`.gitignore` で除外）。
共有するのはこの一覧だけ。**別の端末では、原本のフォルダから下の名前でコピーしてください**
（名前は自由に変えてよい。画面にはファイル名がそのまま出ます）。

原本：`OneDrive - ヒビノ株式会社/04_測定関連データ/音源/ドライソース/`（2026-09-26 にコピー。名前の頭の番号を外した）

PowerShell でまとめてコピーする例（リポジトリ直下で）：

```powershell
$src = "$env:OneDrive_測定関連データ\音源\ドライソース"
$map = @{ "67 トランペット.wav"="トランペット.wav"; "68 サックス.wav"="サックス1.wav"; "69 サックス.wav"="サックス2.wav";
          "70 男声ボーカル.wav"="男声ボーカル.wav"; "71 女声ボーカル.wav"="女声ボーカル.wav";
          "72 ストリングス・カルテット.wav"="ストリングス・カルテット.wav";
          "73 女声アナウンス.wav"="女声アナウンス.wav"; "74 男声アナウンス.wav"="男声アナウンス.wav" }
$map.GetEnumerator() | ForEach-Object { Copy-Item (Join-Path $src $_.Key) (Join-Path "ドライソース" $_.Value) }
```

（`$env:OneDrive` が会社の OneDrive を指さない端末では、`$src` を実際の場所に書き換えてください）
